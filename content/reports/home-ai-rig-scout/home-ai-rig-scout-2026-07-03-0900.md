## Cheapest build paths

### Ultra-cheap Tesla/old server path

- Target: one 650–699 zł Tesla P100 plus the cheapest reliable workstation/server with x16 slot, enough PSU headroom, and forced airflow.
- Required supporting parts: active blower/shroud or server chassis airflow, PCIe power cable/adapters only if electrically correct, boot SSD, Linux host, and test commands (`nvidia-smi`, CUDA sample, llama.cpp/vLLM compatibility check).
- Caveat: 16GB VRAM limits model size, but this is the lowest-cost way to learn datacenter-GPU cooling, drivers, and quantized inference constraints.
