## Cheapest build paths
- **Ultra-cheap Tesla/old server path:** Tesla P100 at ~650–675 zł or P40 if found under ~900 zł, plus a cheap rack/tower server with PCIe x16, riser, 8-pin/EPS power where needed, and forced airflow/fan duct. Best PLN/experiment, worst noise/driver age.
- **AMD Instinct/ROCm path:** only attractive if MI50/MI60/MI100/MI210 is cheap and explicitly PCIe; require ROCm support check for the exact card, kernel, distro and model runtime before buying.
- **Memory-rich EPYC/Xeon base path:** prioritize complete 128–256GB DDR4 RDIMM systems with caddies/PSUs included; GPU compatibility and noise matter more than CPU generation for this test rig.
- **Only-if-cheap RTX path:** RTX 3090 becomes interesting near/under ~3300–3500 zł or in a full system bundle; otherwise Tesla/Instinct paths are cheaper for experiments.

## RAM target notes
- 256GB remains the practical target; accept 128GB if the chassis has open RDIMM/LRDIMM slots and the all-in price stays far below a Mac Studio.
- For servers/workstations, request exact DIMM population, RDIMM vs LRDIMM, maximum supported RAM, free slots, and whether all memory channels are populated.
