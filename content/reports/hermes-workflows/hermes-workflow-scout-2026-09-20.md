# Hermes workflow items worth opening today

- 🔥 Best: My Claude Code is a local control plane/proxy for Claude Code, Codex, OpenCode, Gemini CLI and many other agent CLIs, with provider routing, credential health, cost provenance, web-search proxying and a unified dashboard. [Open My Claude Code](https://github.com/FiredMosquito831/my-claude-code)
- Hermes Deploy packages Hermes Agent gateway, Telegram bot, cron jobs, OpenAI-compatible API and dashboard into a Docker deployment wired for local llama.cpp plus SearXNG/Firecrawl-style retrieval. [Open hermes-deploy](https://github.com/egorcherkasoff/hermes-deploy)
- Maestro runs many full Claude Code sessions in tmux-backed isolated worktrees and gives one conductor agent a live panel plus controls for relaying messages and unsticking workers. [Open Maestro](https://github.com/daniel-madrid-07/Maestro)
- Cones is a terminal workspace for peeking into Claude Code, Codex, pi and OpenCode sessions, returning to past work and launching agents across projects without leaving the dashboard. [Open cones](https://github.com/YuvalSarel1/cones)
- AgentDynamics is an agent APM concept for mapping agent flows, loops, stalls, cost and reliability across LangGraph/OpenTelemetry/SDK traces and Claude Code-style runs. [Open AgentDynamics](https://github.com/Aditya31398/agentdynamics)
- Wostuast is a local tmux reader for multi-agent Claude Code setups that shows which agent needs attention, recent output, changed files and current terminal state without owning the agent process. [Open wostuast](https://github.com/martinus/wostuast)
- Cairn keeps persistent work memory for coding agents as a local graph of plain Markdown updated by deterministic tools, which fits Hermes-style memory rollups and handoffs. [Open Cairn](https://github.com/asitha-w/cairn)
- Agent Governance Suite adds host-neutral skills plus a local MCP workflow gate for Codex and Claude Code to enforce scope, evidence, audit and session-coordination rules instead of relying only on prompt instructions. [Open Agent Governance Suite](https://github.com/jaeseongs95/agent-governance-suite)
- Agent Session Observer auto-discovers local Codex CLI and Claude Code session logs and turns them into daily activity, concurrency and per-session timelines without telemetry or runtime dependencies. [Open Agent Session Observer](https://github.com/yuu-biz/agent-session-observer)
- Omarchy Agent Approvals watches Hermes, Claude Code, Codex, herdr and tmux agents for pending human approvals and turns them into one desktop status light with jump-to-agent actions. [Open Omarchy Agent Approvals](https://github.com/dsskaggs-ai/omarchy-agent-approvals)
