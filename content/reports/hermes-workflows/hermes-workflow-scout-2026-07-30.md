# Hermes workflow items worth opening today

- 🔥 Best: [Agentic Sandbox](https://github.com/jmagly/agentic-sandbox) is a self-hostable KVM/rootless-container runtime for persistent coding agents with A2A dispatch, signed agent cards, shared storage, and a web dashboard.
- [macmini-control-room](https://github.com/nicolasmertens/macmini-control-room) is a local web control plane for Claude Code agents on a Mac Mini, combining cron-driven prompts-as-Markdown, lockfiles, log streaming, and a dashboard.
- [Argus](https://github.com/Elysium-Labs-EU/argus) is a deterministic multi-agent coding supervisor that spawns workers, verifies diffs against git instead of self-reports, and ships PRs.
- [Dreamwork](https://github.com/ultradyn/dreamwork) prototypes a heartbeat-driven autonomous dev loop with dreamer subagents, durable task memory, and a live dashboard.
- [Zhin](https://github.com/zhinjs/zhin) is an AI-native TypeScript bot framework for 20+ chat platforms including Telegram, Slack, Discord, and WeChat, with opt-in agents, MCP, tools, plugins, and security policies.
- [Moxxy](https://github.com/moxxy-ai/moxxy) is a block-based TypeScript agentic loop framework that hot-loads providers, loop strategies, tools, and Telegram/HTTP/terminal frontends around one session model.
- [Session Briefing](https://github.com/CaptCanadaMan/session-briefing) offers a simple pattern for carrying project state across coding-agent sessions via timestamped briefings paired with AGENTS.md or CLAUDE.md plus cross-project rollups.
- [Orloj](https://github.com/OrlojHQ/orloj) is a YAML-declared orchestration runtime for multi-agent systems covering agents, tools, policies, scheduling, routing, and governance.
- [Claude Workflow Composer](https://github.com/fayzan123/claude-workflow-composer) is a visual desktop app for composing multi-agent Claude Code workflows by wiring agents, skills, MCPs, and handoffs for export into `.claude/`.
- [Darc](https://github.com/0xjunha/darc) is a grep-like Git-backed session search tool for sharing and reusing Claude Code/Codex coding-agent memory across projects.
