# Hermes workflow items worth opening today

- 🔥 Best: Falaq Cockpit is a local 127.0.0.1 mission-control dashboard for Claude Code and Codex sessions with live cards, browser approvals, Codex background-task tracking and usage-limit visibility. [Open Falaq Cockpit](https://github.com/Bumoro/falaq-cockpit-oss)
- Gander turns coding-agent sessions into an ambient NOC-style dashboard with Claude Code hooks, alerts, cost guardrails, a task queue, worktrees and test gates. [Open Gander](https://github.com/weellio/gander)
- AI Maestro is an agent orchestration layer for running many Claude, Codex or other agents with persistent memory search, code-graph queries, agent-to-agent messaging and cross-machine movement. [Open AI Maestro](https://github.com/23blocks-OS/ai-maestro)
- Commonly is an open-source workspace where named agents such as Claude Code, Cursor and Codex each get memory, skills and a workstation alongside human collaborators. [Open Commonly](https://github.com/Team-Commonly/commonly)
- archeus is a memory and workspace layer for Claude Code, Codex and terminal agents that preserves per-project state, session history and cost-control context. [Open archeus](https://github.com/babarmuhammad/archeus)
- Basecamp packages shared coding rules, per-project memory, an agent-neutral review gate and token-optimization conventions into a production-ready Claude Code and Codex setup. [Open basecamp](https://github.com/janmaaarc/basecamp)
- houston is a mobile-friendly tmux dashboard for monitoring Claude Code agents remotely and sending instructions from a phone without SSH juggling. [Open houston](https://github.com/noamsto/houston)
- tkzmux is a native macOS session manager that puts Claude Code, Codex and Antigravity sessions into real terminals with repository grouping and hook-derived status. [Open tkzmux](https://github.com/tkz0/tkzmux)
- Temple is an IDE-like session manager for Claude Code and Codex that organizes projects, keeps sessions one click away and makes past runs searchable. [Open Temple](https://github.com/ramsrib/temple)
- Hermes Agent Awesome Plugins is a focused plugin pack for Hermes users covering provider quotas, stalled-tool control, reasoning and iteration budgets, session appearance, memory review and related power-user controls. [Open Hermes Agent Awesome Plugins](https://github.com/apoapostolov/hermes-agent-awesome-plugins)
