# Hermes workflow items worth opening today

- 🔥 Best: Wienerdog is a file-based memory, habits, and daily-routine layer for Claude Code/Codex CLI that maps closely to Hermes skills, memory rollups, and proactive cron routines: https://github.com/wienerdog-ai/wienerdog/
- Fleet is a self-hosted Telegram supergroup control plane for running a fleet of AI coding agents, directly relevant to Hermes gateway UX and multi-agent dispatch from chat: https://github.com/sand0vvv/fleet
- OtoDock is a self-hosted platform for running Claude Code and Codex agents together on a server, useful as a reference for durable agent sessions and remote orchestration: https://github.com/OtoDock/oto-dock/
- Aharness turns Codex workflows into typed state machines with gates, validated evidence, repair paths, and inspectable logs, which is a strong pattern for safer Hermes autonomous coding loops: https://github.com/Alfredvc/aharness
- OpenLore provides deterministic local-first memory and guardrails for coding agents without an LLM in the hot path, worth studying for reliable project memory and policy enforcement: https://github.com/clay-good/OpenLore
- Ellmos connectors offers framework-decoupled messaging connectors for Telegram, Discord, Signal, WhatsApp, Home Assistant, and webhooks, useful for modularizing Hermes gateway adapters: https://github.com/ellmos-ai/connectors
- Mac Mini Control Room is a web control plane for cron-driven Claude Code agents with prompt-as-Markdown, lockfiles, log streaming, and a dashboard, matching Hermes proactive-agent infrastructure needs: https://github.com/nicolasmertens/macmini-control-room
- Aesop is a SQLite event-sourced multi-agent software-development harness with model-swappable orchestrators, a web dashboard, and secret-scan gates, relevant to Hermes task history and dashboard design: https://github.com/matt82198/aesop
- KOVO combines Telegram, a mission-control dashboard, autonomous routines, owner-approved skill learning, voice, MCP, and a store into a self-hosted agent, making it a useful comparison for Hermes product surface: https://github.com/Ava-AgentOne/KOVO
- gptme remains a mature terminal agent with local tools and persistent-agent primitives that can inform Hermes CLI ergonomics and long-running local workflows: https://github.com/gptme/gptme
