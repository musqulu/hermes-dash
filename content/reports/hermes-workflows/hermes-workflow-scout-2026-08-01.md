# Hermes workflow items worth opening today

- 🔥 Best: Fleet is a self-hosted Telegram-supergroup controller where each Claude Code/Codex worker gets its own topic, making it directly relevant to topic-scoped mobile agent orchestration: https://github.com/sand0vvv/fleet
- OtoDock packages Claude Code and Codex as a self-hosted multi-agent server with a live dashboard, BYO subscriptions, sandboxing, and MCP-oriented infrastructure ideas: https://github.com/OtoDock/oto-dock
- relaymux is a lightweight tmux-backed harness for coordinating local coding-agent CLIs with scheduled requests and Telegram/iMessage replies while keeping agents as visible local processes: https://github.com/mupt-ai/relaymux
- oh-my-dag offers a DAG execution layer with typed nodes, concurrent fan-out, model verification gates, self-consolidating memory, skills, and MCP tools that could inspire stronger Hermes workflow primitives: https://github.com/AbyssCN/oh-my-dag
- tuneloop turns coding-agent session transcripts into a local analytics dashboard with outcome links, autonomy scoring, tool-error categories, and re-steer pattern detection: https://github.com/tuneloop/tuneloop
- aharness enforces long-running Codex workflows as state machines with typed gates, validated evidence, repair paths, and inspectable logs to reduce process drift: https://github.com/Alfredvc/aharness
- MWE-MCP is a self-hosted MCP memory server that stores structured, ACL-aware, human-readable Markdown wiki fragments for shared agent memory: https://github.com/Fr4nZ82/mwe-mcp
- BarrelShell is a plain-Python local agent shell with editable Markdown personality/memory, Ollama, Telegram and web chat, cron-style pulse tasks, skills, and approval gates: https://github.com/jkries/barrelshell
- ellmos connectors provide framework-decoupled messaging adapters for Telegram, Discord, Signal, WhatsApp, Home Assistant, and webhooks with a SecretAdapter pattern worth comparing against Hermes gateway adapters: https://github.com/ellmos-ai/connectors
- AstrBot is a mature IM-focused agent platform with plugins, personas, MCP, skills, knowledge bases, multimodal support, and automatic context compression across messaging apps: https://github.com/AstrBotDevs/AstrBot
