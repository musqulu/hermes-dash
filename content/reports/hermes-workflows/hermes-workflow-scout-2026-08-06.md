# Hermes workflow items worth opening today

- 🔥 Best: Prime Agent is a self-improving coding-agent stack for long-running autonomous tasks, useful as a reference for Hermes persistent task execution, RLM feedback loops, and evaluation harnesses. [PrimeIntellect-ai/prime-agent](https://github.com/PrimeIntellect-ai/prime-agent)
- Hy4ri's Hermes mobile client targets real-time Hermes chat, cron management, and session resume from a phone, making it directly relevant to Telegram/mobile control surfaces. [Hy4ri/hermes-mobile](https://github.com/Hy4ri/hermes-mobile)
- YantrikDB's Hermes plugin proposes a self-maintaining memory provider with recall ranking, contradiction tracking, and proactive maintenance hooks. [yantrikos/yantrikdb-hermes-plugin](https://github.com/yantrikos/yantrikdb-hermes-plugin)
- Dagu is a local-first YAML workflow engine for scripts, SSH, containers, and AI agents that could inspire more observable cron/proactive job orchestration. [dagucloud/dagu](https://github.com/dagucloud/dagu)
- Tuneloop is a local CLI for analyzing coding-agent session transcripts, useful for building Hermes session-quality analytics and workflow retrospectives. [tuneloop/tuneloop](https://github.com/tuneloop/tuneloop)
- BlackFlare watches Claude/Codex runs, keeps macOS awake, and sends Telegram or Slack notifications when agents finish or need input. [BlackFlare](https://blackflare.dev/)
- Armature focuses on MCP and CLI session analytics, replay, and evals, which maps well to Hermes tool-call observability and workflow-to-eval conversion. [Armature](https://armature.tech/)
- Reware Labs Security Cards provide machine-readable secure-usage guidance for libraries, a practical pattern for safer coding-agent context injection. [Reware-Labs/securitycards](https://github.com/Reware-Labs/securitycards)
- Rudder repurposes unit tests to measure how much coding agents improvise, offering a lightweight idea for agent reliability probes around Hermes tasks. [RudderCode/Rudder](https://github.com/RudderCode/Rudder)
