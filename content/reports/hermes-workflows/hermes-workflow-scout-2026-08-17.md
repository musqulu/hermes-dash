# Hermes workflow items worth opening today

- 🔥 Best: AgentConnect is a cross-surface agent tagging layer for Slack, Telegram, Discord, Lark, GitHub, and webhooks, useful as a reference for Hermes gateway routing and multi-agent mentions. [GitHub](https://github.com/agentconnect-md/agentconnect)
- VNX Orchestration runs Claude, Codex, Gemini, Kimi, and Ollama CLI workers in tmux worktrees with review gates and append-only NDJSON receipts. [GitHub](https://github.com/Vinix24/vnx-orchestration)
- cicy-code is a local-first tmux worker workspace with WebTTY terminals, a React control surface, an AI gateway, skill marketplace, and Telegram Mini App direction. [GitHub](https://github.com/cicy-ai/cicy-code)
- Plan2Agent turns a short product note into confirmed scope, approved specs, dependency-aware tasks, and verified coding-agent run logs for Codex, Claude Code, and Gemini CLI. [GitHub](https://github.com/silbaram/plan2agent)
- Arnold’s Megaplan decomposes software work into prep, plan, critique, gate, revise, execute, and review phases so cheaper models can run bounded parts of an agent workflow. [GitHub](https://github.com/peteromallet/Arnold)
- Jaroku is a local-first workbench that generates LangGraph agents, traces every LLM/tool/state transition, supports mid-run forks, and compares quality, latency, and cost across providers. [GitHub](https://github.com/jackeddisciple/Jaroku)
- OpenSRE is an open-source framework for building AI SRE agents with 60+ operational tools, explicit workflows, and a training/evaluation environment. [GitHub](https://github.com/Tracer-Cloud/opensre)
- mu packages news, mail, search, weather, markets, video, files, contacts, calendar, and documents behind one MCP server plus a human web app. [GitHub](https://github.com/micro/mu)
- Claude Code Plugin Tracker is a GitHub Actions-updated catalog of Claude Code plugins, extensions, and hooks that can inspire a similar Hermes ecosystem watcher. [GitHub](https://github.com/linny006/claude-code-plugin-tracker)
- agent-project-bootstrap is a FOSS template with shared AGENTS.md rules, CI, security defaults, memory, and golden-path stubs for projects that expect coding agents from day zero. [GitHub](https://github.com/edwardlthompson/agent-project-bootstrap)
