# Hermes workflow items worth opening today

- 🔥 Best: agentic-workflow packages a strict ticket-to-delivery loop for Claude Code and Codex with isolated worktrees, evidence gates, independent review, and tracker handback. [Open agentic-workflow](https://github.com/o-m-a-r-k/agentic-workflow)
- OptChat is a no-dependency MCP memory server that stores full Claude Code and Codex transcripts, folds them into expandable summary trees, and lets agents maintain the summaries themselves. [Open OptChat](https://github.com/samoylenkodmitry/optchat)
- mcp-janitor shows which MCP servers Codex, Claude Desktop, Cursor and VS Code keep alive per conversation, then stops idle servers automatically. [Open mcp-janitor](https://github.com/Rober1208/mcp-janitor)
- agent-harness installs shared rules, memory, retrieval, lessons and command guards across Claude Code, Codex, Copilot, Cursor, Gemini CLI and other coding tools. [Open agent-harness](https://github.com/hihihhi/agent-harness)
- Tesserix Crew wraps local coding CLIs into one persistent session with shared skills, task commands, rule-based routing and bounded MCP delegation. [Open Tesserix Crew](https://github.com/tesserix/tesserix-crew)
- agentbox moves coding agents onto a self-hosted VPS workspace with browser and phone check-ins, previews, project sessions and always-on orchestration. [Open agentbox](https://github.com/jabezpauls/agentbox)
- multi-agents is a hub where Claude Code, Codex, OpenCode, Gemini CLI, Aider or custom scripts coordinate through shared messages, tasks, file locks and a dashboard. [Open multi-agents](https://github.com/toroc07/multi-agents)
- Agent Bullpen visualizes Claude Code and Codex teams by reading existing transcripts, showing who launched whom, current status, agent conversations, costs and usage-limit resets. [Open Agent Bullpen](https://github.com/bemong1/agent-bullpen)
- xcheck fans one immutable review packet out to other agent CLIs, captures answer files per lane, and leaves consensus judgment to the orchestrating model. [Open xcheck](https://github.com/yarco/xcheck)
- cross-agent-cli runs headless Claude, Codex and Grok processes as one team through an MCP server and launcher skill, with solo and dev-team modes. [Open cross-agent-cli](https://github.com/WSH95/cross-agent-cli)
