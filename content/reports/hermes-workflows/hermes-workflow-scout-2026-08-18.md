# Hermes workflow items worth opening today

- 🔥 Best: ccteam turns Claude Code, Codex, Grok, Kimi, and DeepSeek Harness sessions into a cross-machine team controllable from Telegram, Lark, or a browser. [GitHub](https://github.com/firstintent/ccteam)
- Instar packages persistent Claude Code or Codex agents with scheduling, sessions, memory, contradiction checks, and Telegram access. [GitHub](https://github.com/JKHeadley/instar)
- Coddy Agent is a single static Go binary with a ReAct loop, MCP, skills, embedded web UI, Telegram gateway, cron scheduler, long-term memory, and context compaction. [GitHub](https://github.com/coddy-project/coddy-agent)
- Memorix provides a local-first shared project memory layer over MCP for Claude Code, Codex, Gemini CLI, OpenCode, Hermes Agent, and other coding agents. [GitHub](https://github.com/AVIDS2/memorix)
- Agent Manager is a tmux TUI for live agent status, quick prompts, git worktrees, and diff review across coding-agent sessions. [GitHub](https://github.com/YoanWai/agent-manager)
- run-kit exposes existing tmux panes as a phone-friendly remote console and can spawn coding agents in parallel git worktrees without wrapping the agents. [GitHub](https://github.com/sahil87/run-kit)
- HarnessRouter offers a self-hosted unified API for running Codex, Claude Code, Hermes, and other agent harnesses with sessions, streaming, files, cancellation, and failure handling. [GitHub](https://github.com/harnessrouter/harnessrouter)
- seek is a DeepSeek-first local coding-agent platform with plan mode, parallel sub-agent teams in isolated worktrees, cron, memory, and MCP in one Go binary. [GitHub](https://github.com/whyiyhw/seek)
- DorkOS is a self-hosted mission-control dashboard for Claude Code, Codex, and OpenCode sessions with approvals and scheduling. [GitHub](https://github.com/dork-labs/dorkos)
- memento is a durable multi-agent memory system with MCP access, reviewed Git writes, rebuildable FTS5/graph indexes, and scheduler state. [Project page](https://rcarmo.github.io/projects/memento/)
