# Hermes workflow items worth opening today

- 🔥 Best: herdr-telegram-agents maps each live Herdr coding agent to a Telegram forum topic with status icons, two-way chat, inline answers and private operator alerts, a very close fit for topic-scoped Hermes control. [Open herdr-telegram-agents](https://github.com/permgps/herdr-telegram-agents)
- Dispatch is a Telegram group gateway where teammates post tasks, an agent plans them, humans approve, and Claude Code/Codex/Gemini work in isolated git worktrees before reporting back. [Open Dispatch](https://github.com/astvision/dispatch)
- ATC is an “air traffic control” dashboard that puts Claude Code and Codex sessions, git worktrees and Linear tickets on one radar screen. [Open ATC](https://github.com/chaehy5665/atc)
- Telegram account MCP exposes a local read-first Telegram user-account bridge over stdio for Codex and Claude Code, useful when bot-token Telegram access is too limiting. [Open telegram-account-mcp](https://github.com/Vlislavn/telegram-account-mcp)
- Claude Deck is a native macOS dashboard concept for Claude Code live sessions, searchable history, cost tracking, token-saving advice and MCP/hooks/permissions management. [Open Claude Deck](https://github.com/ferrousdesigner/claude-deck)
- usage-watch watches tmux-hosted Claude Code, Codex and OMP agents stalled on usage limits and can nudge them after the pool refills. [Open usage-watch](https://github.com/tucktuck101/usage-watch)
- ai-memory is a Markdown-backed long-term memory plugin with session summaries, `/clear` chaining, MCP/hooks and lazy rule loading for Claude Code and Codex-style sessions. [Open ai-memory](https://github.com/dankinsoid/ai-memory)
- Throughline captures commands, file changes, decisions and live git/PR state so Claude Code, Codex CLI and OpenCode sessions can hand off readable state instead of replaying whole chats. [Open Throughline](https://github.com/dynamic/throughline)
- Nexus Memory is a local shared-memory layer marketed across Hermes, OpenClaw, Claude Code, Codex and Cursor, worth inspecting for cross-agent memory schema and deployment ideas. [Open Nexus Memory](https://github.com/Neboy72/nexus-memory)
- Hive is a Rust fleet console for Claude Code and Codex sessions running in tmux on always-on boxes, with host/hub daemons plus CLI, Tauri and phone-control surfaces. [Open Hive](https://github.com/torsor/hive)
