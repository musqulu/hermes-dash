# Hermes workflow items worth opening today

- 🔥 Best: cc-haha is a mature desktop workspace for Claude Code-style agents with multi-session management, Git worktrees, diff review, skill marketplace, multi-model support and mobile/chat access. [Open cc-haha](https://github.com/NanmiCoder/cc-haha)
- AgentDeck is a small self-hosted fleet panel where each Claude Code agent runs in a persistent tmux session with browser terminals, live status and a Telegram bridge. [Open AgentDeck](https://github.com/yanhs/agentdeck)
- Claude Fleet adds a server-side verify gate to a tmux/browser coding-agent fleet so agent branches only land after rebase and tests pass outside the model’s control. [Open Claude Fleet](https://github.com/jp290/claude-fleet)
- Hermes Analytics is a Hermes plugin that records LLM calls, tool calls, context pressure, approvals, Kanban events and fleet telemetry into profile-scoped SQLite. [Open Hermes Analytics](https://github.com/dyiapanis/hermes-analytics)
- Hermes Bot Forge is a Hermes plugin for creating role-specific bot profiles with SOUL.md, starter memory, tools, skills, routines, gateway setup and rollback checks. [Open Hermes Bot Forge](https://github.com/BkashJEE/hermes-bot-forge)
- elepha indexes local Claude Code, Codex and OpenCode transcripts into encrypted SQLite and exposes read-only recall through MCP without modifying source sessions. [Open elepha](https://github.com/aldanux/elepha)
- ecotokens compresses verbose shell, read and search outputs through agent hooks and tracks real token savings in a local TUI dashboard. [Open ecotokens](https://github.com/hansipie/ecotokens)
- ORRERY Telemetry gives Claude Code and Codex agents a lightweight mail layer, launcher hooks and dashboard so multiple agents can coordinate without human copy-paste. [Open ORRERY Telemetry](https://github.com/gyroid-eth/orrery-telemetry)
- 4top is a keyboard-first tmux dashboard for attaching to Claude Code, Codex and Pi sessions while preserving native session history and avoiding a persistent daemon. [Open 4top](https://github.com/4ier/4top)
- Glimmervoid is a Windows-first dashboard for supervising many Claude Code agents with live terminals, hook-based status detection and per-agent worktree review. [Open Glimmervoid](https://github.com/johncwaters/glimmervoid)
