# Hermes workflow items worth opening today

- 🔥 Best: Fleet is a Telegram-first control plane for driving a fleet of Claude Code/Codex agents, directly relevant to Hermes mobile orchestration and topic-scoped agent routing: https://github.com/sand0vvv/fleet
- TerminAI explores popping any CLI agent into an existing terminal only when needed, a useful UX pattern for Hermes shell workflows without always-on agent takeover: https://terminai.app
- WhipDesk turns a phone into a remote control surface for a full dev machine, a practical reference for Telegram/mobile approvals, task steering, and remote coding sessions: https://github.com/BinaryBananaLLC/WhipDesk
- Corv focuses on robust SSH execution for AI agents, worth studying for Hermes remote-terminal reliability and persistent infrastructure operations: https://github.com/khalid-src/corv-client
- Setoku is a self-hosted knowledge server for AI agents, useful as a reference for durable memory rollups and searchable agent context stores: https://setoku.com
- Mwe-MCP provides a self-hosted MCP memory service that tracks who may know what, a concrete pattern for team/profile-aware memory routing: https://github.com/Fr4nZ82/mwe-mcp
- OneCLI is an open-source credential gateway designed to keep secrets out of AI agents, relevant to safer Hermes tool execution and gateway command approvals: https://github.com/onecli/onecli
- OtoDock runs Claude Code and Codex as a team of server-side agents, a useful comparison point for Hermes multi-profile worker orchestration and dashboards: https://github.com/OtoDock/oto-dock/
- Dagu is a local-first DAG workflow engine with an MCP server, worth testing as a complement or integration model for Hermes cron and proactive workflows: https://github.com/dagucloud/dagu
- n8n-mcp lets coding agents build n8n workflows through MCP, a practical source of ideas for turning Hermes scouts into editable automations: https://github.com/czlonkowski/n8n-mcp
