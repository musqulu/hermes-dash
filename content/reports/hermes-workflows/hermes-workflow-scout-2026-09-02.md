# Hermes workflow items worth opening today

- 🔥 Best: Cogpit is a desktop/browser control center for Claude Code, Codex and Copilot CLI sessions that watches, steers, approves and restores agents from their native histories. [gentritbiba/cogpit](https://github.com/gentritbiba/cogpit)
- GroupConnect is a multi-platform group-chat gateway for local CLI agents with sliding context, member security and support for Telegram, Discord, Slack, Feishu and WeCom. [sapereaude2014/GroupConnect](https://github.com/sapereaude2014/GroupConnect)
- telegram-mcp-kit packages a production-tested setup path and patches for giving Claude Code, Codex or any MCP client access to a user-owned Telegram account. [tonydzi/telegram-mcp-kit](https://github.com/tonydzi/telegram-mcp-kit)
- claude-cron is a macOS launchd scheduler for headless Claude Code loops with cheap prechecks, parallel jobs, reboot survival, a web dashboard and searchable run logs. [lmelomoura/claude-cron](https://github.com/lmelomoura/claude-cron)
- shadok-ai runs many Claude Code sessions in separate git worktrees with browser or Telegram answers to blocked questions and agent-spawned subagents. [shadok-ai/shadok-ai](https://github.com/shadok-ai/shadok-ai)
- AgentsCommander is a desktop app for running recurring multi-CLI coding-agent teams on loops, useful as a reference for scheduled “dark factory” experiments. [mblua/AgentsCommander](https://github.com/mblua/AgentsCommander)
- ccdeck turns Claude Code and Codex sessions into a live DAG of tool calls, cost, quota and human-blocked nodes instead of a linear terminal scroll. [BarganConstantin/ccdeck](https://github.com/BarganConstantin/ccdeck)
- Argus uses per-machine Go sidecars plus a web control plane to stream and manage Claude Code, Codex, Cursor CLI or custom agents across multiple hosts. [kr4t0n/argus](https://github.com/kr4t0n/argus)
- Memstem is a pull-based unified memory and skill service that ingests filesystem-backed agent knowledge into one canonical Markdown and SQLite store exposed via MCP. [Memstem/memstem](https://github.com/Memstem/memstem)
- remem automatically captures, distills, searches and injects engineering memory across Claude Code and Codex sessions through hooks, MCP, CLI and a localhost API. [majiayu000/remem](https://github.com/majiayu000/remem)
