# Hermes workflow items worth opening today

- 🔥 Best: AgentHydra is a local, private, MCP-native control room that puts Claude Code, Codex and OpenCode sessions in one queueable dashboard with isolated Claude Desktop instances: [LunarWerxs/AgentHydra](https://github.com/LunarWerxs/AgentHydra)
- Agent Network shows a one-command multi-agent team where Claude, Codex and Grok can route work to each other through MCP/SSE with a web dashboard: [sleep2agi/agent-network](https://github.com/sleep2agi/agent-network)
- Maestro-Flow is an intent-driven lifecycle engine for multi-agent development with planning, scheduling, verification, a knowledge graph and a visual dashboard: [catlog22/maestro-flow](https://github.com/catlog22/maestro-flow)
- Magec is a self-hosted multi-agent platform with visual workflows, voice control, Telegram/Discord/Slack access, cron, memory and MCP tools: [achetronic/magec](https://github.com/achetronic/magec)
- BrainLayer is a persistent-memory MCP using SQLite and a knowledge graph with separate tool surfaces for agents and humans, useful for Hermes memory-rollup design: [EtanHey/brainlayer](https://github.com/EtanHey/brainlayer)
- Osaurus is a native macOS offline agent harness combining models, tools, persistent memory, autonomous execution and cryptographic identity in a local Swift app: [osaurus-ai/osaurus](https://github.com/osaurus-ai/osaurus)
- Monomind extends Claude Code with a local MCP server for codebase knowledge graphs, persistent memory and self-coordinating agent organizations: [monoes/monomind](https://github.com/monoes/monomind)
- Kelos is a Kubernetes-native framework for orchestrating autonomous coding agents, useful as an infrastructure reference for durable Hermes workers: [kelos-dev/kelos](https://github.com/kelos-dev/kelos)
- Hodor is an agentic reviewer for GitHub, GitLab, Gitea, Forgejo and local diffs that uses read-only tools for multi-step code analysis: [mr-karan/hodor](https://github.com/mr-karan/hodor)
- GitMir Local maps code into business objects, logic and dependencies and serves relevant context over MCP, making it a useful reference for agent-readable project context: [gitmir-hello/gitmir-local](https://github.com/gitmir-hello/gitmir-local)
