# Hermes workflow items worth opening today

- 🔥 Best: MemVault is a local-first memory layer for coding agents with one SQLite file, audited fact extraction, MCP tools, REST, CLI and a dashboard. [Open MemVault](https://github.com/zhang66633/memvault)
- Cubicle is a read-only live office dashboard for Claude Code, Codex, Gemini CLI and other agents, with raised-hand status and Telegram alerts via a tiny JSON feed. [Open Cubicle](https://github.com/caglarutkuguler/cubicle)
- AgenticOS Workbench gives Claude Code and Codex a shared plain-Markdown vault, recall, session capture and an approval-first “Chief of Staff” loop. [Open AgenticOS Workbench](https://github.com/zzoretich/AgenticOS-Workbench)
- Elephant stores source-backed development lessons through Codex and Claude Code hooks, then recalls relevant experience through MCP, CLI and a local dashboard. [Open Elephant](https://github.com/prithivrajmu/elephant)
- Cortadel is a self-hosted temporal graph memory system for agents that tracks superseded facts, contradictions, duplicate entities and stale knowledge over time. [Open Cortadel](https://github.com/cortadel/cortadel)
- AGENTS.md collects reusable Codex rule groups for multi-agent routing, task hygiene, Caffeine keep-awake mode, Telegram notifications, GitHub publishing and network fetching. [Open AGENTS.md](https://github.com/tsetsugekka/AGENTS.md)
- Agent Wrapper prototypes a safety gate around Claude Code and Codex where regex rules and Ollama triage escalate dangerous operations to a human approval dashboard. [Open Agent Wrapper](https://github.com/NewAITees/agent-wrapper)
- Workbench Core turns Claude Code into a persistent collaborator with persona rules, JSONL session capture, background summaries and a lazy-started memory MCP. [Open Workbench Core](https://github.com/mike-bronner/workbench-core)
- ctxbin is a deterministic CLI for saving and reloading repo context, skills and agent rules through branch-inferred keys for repeatable AI-agent handoffs. [Open ctxbin](https://github.com/superlucky84/ctxbin)
- AMP is an MCP-native memory server that frames agent memory as a reusable protocol and ships a Python package for adding “hippocampus” storage to LLM workflows. [Open AMP](https://github.com/akshayaggarwal99/amp)
