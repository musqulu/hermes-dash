# Hermes workflow items worth opening today

- 🔥 Best: [flowkit](https://github.com/ahlerjam/flowkit) is a Claude Code plugin that turns GitHub issues into an autonomous backlog-and-runner loop with hard budgets, model tiering, setup commands, and layered verification.
- [hamroh](https://github.com/Rustam-Z/hamroh) is a self-owned Telegram AI companion framework with persistent memory, scheduled tasks, MCP/tool extension points, logs, and editable rules.
- [Detent](https://github.com/digitaldrywood/detent) is a board-driven single-binary agent orchestrator that watches GitHub Projects, runs ready issues in isolated worktrees, validates them, and serializes merges.
- [agent-handler](https://github.com/mturley/agent-handler) manages parallel Claude Code sessions with a SQLite event ledger, pub/sub inboxes, GitHub/Jira watchers, terminal peeking, cmux integration, and a web dashboard.
- [tuneloop](https://github.com/tuneloop/tuneloop) builds a local analytics dashboard from coding-agent transcripts to attribute costs to shipped outcomes and surface autonomy, complexity, decisions, and tool-error patterns.
- [OpenMetaHarness](https://github.com/openmetaharness/openmetaharness) packages a one-file bootloader pattern for long-horizon coding-agent projects that need durable memory, verified decisions, and cross-session continuity.
- [OpenLore](https://github.com/clay-good/OpenLore) offers deterministic local-first codebase memory and guardrails for coding agents using static analysis instead of an LLM in the hot path.
- [Reviewflow](https://github.com/DGouron/review-flow) automates Claude Code reviews for GitLab MRs and GitHub PRs with webhook-driven queues, progress tracking, MCP integration, deduplication, and follow-up reviews.
- [GitHub Agentic Workflows MCP Gateway](https://github.com/github/gh-aw-mcpg) exposes configured MCP servers to sandboxed GitHub Agentic Workflows agents through a gateway model that could inform safer tool routing.
- [Agent Skill Exchange](https://github.com/agentskillexchange/skills) is a large curated catalog of reusable agent skills with category browsing and verification metadata that is directly relevant to Hermes skill distribution.
