# Hermes workflow items worth opening today

- 🔥 Best: Galvanize is a push-trigger layer that wakes fresh Hermes, Claude, or Codex sessions from mail, folders, git commits, webhooks, or scripts, which is directly useful for event-driven proactive agents beyond cron polling. [jarvis959/galvanize](https://github.com/jarvis959/galvanize)
- Wiki Knowledge Agent is a zero-dependency skill that turns pasted links and text into a verified, translated, searchable wiki, making it a practical pattern for lightweight memory rollups that stay human-readable. [atukunare/wiki-knowledge-agent](https://github.com/atukunare/wiki-knowledge-agent)
- Hermes Herdr Plugin lets Hermes spawn, track, read, relay, and focus Claude Code, Codex, Pi, or other Herdr-managed terminal workstreams through a persistent ledger. [steven-terrana/hermes-herdr-plugin](https://github.com/steven-terrana/hermes-herdr-plugin)
- Time Strike is a local MCP server that converts a human deadline into deterministic explore, execute, validate, finalize, and emergency budget signals for long-running agents. [JuanCG13/time-strike](https://github.com/JuanCG13/time-strike)
- Centered Agent Memory builds one read-only searchable index over Claude Code, Claude Desktop, Codex, Cursor, Gemini, Antigravity, and Devin conversations, exposed by CLI and MCP. [arlinamid/centered-agent-memory](https://github.com/arlinamid/centered-agent-memory)
- Holdfast is a zero-infra repo discipline layer for coding agents that combines memory hygiene, context-budget rules, and a real Definition of Done to reduce “almost right” completions. [kiharachiaki-gif/holdfast](https://github.com/kiharachiaki-gif/holdfast)
- Forkestra CLI parses a Markdown spec into deterministic frontend/backend task plans and dispatches Claude Code, Codex, or OpenCode workers with persisted run state. [MrPinguiiin/forkestra-cli](https://github.com/MrPinguiiin/forkestra-cli)
- Maestrus is a self-hostable desktop, web, and phone conductor for orchestrating Claude Code and Codex across multiple codebases on your own machines. [joaoventuri/maestrus](https://github.com/joaoventuri/maestrus)
- Agent Config Manager inventories Claude Code plugins, MCP servers, skills, cloud settings, project scopes, and environment tools, flagging missing setup across local and cloud contexts. [itsLeonB/agent-config-manager](https://github.com/itsLeonB/agent-config-manager)
- LatentCode targets hidden agent-generated defects such as disconnected code, broken end-to-end wiring, production mocks, and missing env vars through CLI, MCP, slash-skill, pre-commit, and dashboard interfaces. [Hemanthdamineni/latentcode](https://github.com/Hemanthdamineni/latentcode)
