# Hermes workflow items worth opening today

- 🔥 Best: SquadCue turns local AI CLI sessions into named, resumable workers with a web and Telegram approval inbox, directly useful for Hermes gateway supervision and risky-tool gating. [GitHub](https://github.com/hsienchuc/squadcue)
- Catalyst packages a token-efficient Claude Code workspace around research, planning, implementation, validation, parallel agents, and persistent memory. [GitHub](https://github.com/coalesce-labs/catalyst)
- Animus CLI runs multi-model dev teams from YAML workflows with daemon scheduling and MCP integration, a strong reference for Hermes worktree agents and recurring execution. [GitHub](https://github.com/launchapp-dev/animus-cli)
- Titen is a local SQLite MCP memory server with source, read-scope, and contradiction evidence, worth comparing against Hermes memory rollups. [GitHub](https://github.com/RamaAditya49/titen)
- Engramory defines a zero-infrastructure file-based memory protocol with validators and standing-rule loading, useful for lightweight profile memory hygiene. [GitHub](https://github.com/tinqiao-oss/engramory)
- Agent Scheduler is an MCP scheduling server for cron, intervals, priority queues, dependencies, and retries that maps cleanly onto proactive Hermes workflows. [GitHub](https://github.com/nyx-builds/agent-scheduler)
- pandev CLI breaks down AI coding-agent cost by task, branch, model, and file in a local dashboard, a good model for Hermes usage analytics UX. [GitHub](https://github.com/pandev-metriks/pandev-cli)
- agenthropic reads Claude Code JSONL transcripts into a local subagent DAG with cost attribution, relevant to Hermes session and child-agent observability. [GitHub](https://github.com/IvanBBaev/agenthropic)
- Kael is a Go agent runtime with tool loops, scheduled workflows, delegation, memory, identity, and Slack/Telegram messaging interfaces. [GitHub](https://github.com/unitz007/open-kael)
- Kery gives AI dev agents annotated screenshot evidence for tested web-app behavior, a practical pattern for verified Hermes build reports. [GitHub](https://github.com/Kery-HQ/Kery)
