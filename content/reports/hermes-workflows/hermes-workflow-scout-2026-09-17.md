# Hermes workflow items worth opening today

- [Merv](https://github.com/rapidreview-io/Merv) gives coding agents a gated experiment workflow for ML/research projects, with plan review, execution review, and human-observable run state that maps well to Hermes cron or dashboarded research loops.
- [agentproto/ts](https://github.com/agentproto/ts) is a TypeScript daemon/runtime for running multiple coding-agent CLIs in the background, attaching checks before commits land, and exposing workflows through CLI/HTTP/MCP surfaces.
- [PersonalClaw](https://github.com/PersonalClaw/PersonalClaw) is a self-hosted personal agent OS with chat, autonomous goal loops, long-term memory, skills, scheduled automation, channel integrations, and a local dashboard.
- [Pal](https://github.com/OtakuNathan/Pal) is a long-running single-user agent runtime centered on service operation, messaging channels, governed capabilities, event-driven tasks, and durable workflow delegation.
- [AOS — Agent Operating System](https://github.com/MagicalYuYu/agent-operating-system) packages cross-session memory, project isolation, skills, a file-system-like kernel, and a visual desktop metaphor for coding-agent state management.
- [ai-flow](https://github.com/nazarovsa/ai-template) is a reusable agent-development workflow that turns an idea into PRD, specs, atomic tasks, autonomous execution, and self-maintaining docs/Serena memory.
- [stark-skills](https://github.com/21StarkCom/stark-skills) offers Claude Code and Codex lifecycle plugins for human-gated specs/plans, check-gated builds, evidence-contract PR review, IaC review, and session ops.
- [Loom](https://github.com/tusharmewara/homebrew-loom) aims to share skills, MCP servers, sessions, and workflow execution across multiple AI coding tools instead of keeping each CLI siloed.
- [tterm-agent](https://github.com/tterm-net/tterm-agent) shows a reversed-connection pattern for controlling a local terminal from Telegram without opening inbound ports, useful for thinking about phone-first Hermes access.
- [AgentDrive](https://tokencanopy.com/products/agentdrive) is a new persistent, versioned file-storage product for AI agents that is worth studying as a design reference for agent-owned artifacts and rollbackable workspace state.
