# Hermes workflow items worth opening today

- 🔥 Best: CCGram maps Telegram forum topics to live tmux or Herdr sessions so Claude Code, Codex CLI and Gemini can be monitored and steered from a phone without losing terminal continuity. [alexei-led/ccgram](https://github.com/alexei-led/ccgram)
- AgEnD is a Telegram/Discord fleet daemon for Claude Code, Codex, OpenCode and Gemini with crash recovery, schedules, cost guards, peer collaboration and a live web dashboard. [songsid/AgEnD](https://github.com/songsid/AgEnD)
- FlowBoard combines local-first project context, decisions, specs and agent-native Kanban so coding agents can pull only the task state they need. [rasimme/FlowBoard](https://github.com/rasimme/FlowBoard)
- MARM Memory is a local MCP memory server that fuses session history, codebase indexing and concept graphs for Claude Code, Codex, Gemini and Cursor. [Lyellr88/marm-memory](https://github.com/Lyellr88/marm-memory)
- Commitlore keeps constraints, rejected alternatives and architectural decisions in Git and filters recall to decisions still in force. [MongLong0214/commitlore](https://github.com/MongLong0214/commitlore)
- Harness Arena compares agent harnesses rather than models by running the same task in isolated workspaces and collecting blind human judgments into an Elo leaderboard. [Ondemand-OSS/harness-arena](https://github.com/Ondemand-OSS/harness-arena)
- OmniTerm is a browser UI for Claude Code, Codex, OpenCode, Qwen and other CLI agents with live status, approvals, terminal access and mobile-friendly monitoring. [GDWhisper/OmniTerm](https://github.com/GDWhisper/OmniTerm)
- Telegram Agent Router exposes live Claude Code and Codex CLI sessions through per-machine Telegram bots with session selection, branch/status previews and reply-based routing. [hyunsoogo/telegram-agent-router](https://github.com/hyunsoogo/telegram-agent-router)
- Inspeximus focuses agent memory on corrected facts, letting a user retire or undo stale facts by key while preserving auditable provenance. [DanceNitra/inspeximus](https://github.com/DanceNitra/inspeximus)
- Switchboard is a desktop command center for browsing, launching, resuming and monitoring Claude Code, Codex, Hermes, Pi and Antigravity sessions across projects. [deadeye636/switchboard](https://github.com/deadeye636/switchboard)
