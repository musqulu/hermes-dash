# Hermes workflow items worth opening today

- 🔥 Best: Pond makes Claude Code, Codex and other agent sessions losslessly searchable, SQL-queryable and restorable across clients through local or S3 storage plus MCP recall. [tenequm/pond](https://github.com/tenequm/pond)
- tlive adds self-hosted remote approvals and live monitoring for Claude Code or Codex through Telegram, Feishu or a web terminal without proxying sessions off your machine. [y49/tlive](https://github.com/y49/tlive)
- Codey is a local-first macOS workbench for orchestrating Claude Code, Codex, OpenCode and pi across project workspaces, worker teams, chat surfaces and voice. [its-ahoh/codey](https://github.com/its-ahoh/codey)
- ccmux watches existing tmux panes running Claude Code, Codex, Cursor, OpenCode, Pi, Gemini and other agents, then surfaces which sessions are idle, busy or waiting for help. [epilande/ccmux](https://github.com/epilande/ccmux)
- dev-3.0 turns a one-person studio into a kanban-and-worktree control plane where each coding-agent task gets its own sandboxed terminal and review path. [h0x91b/dev-3.0](https://github.com/h0x91b/dev-3.0)
- Wax is a single-file local memory layer for Foundation Models, Claude, Cursor, Codex and Hermes with Apple Silicon-optimized retrieval over text, photos and video. [christopherkarani/Wax](https://github.com/christopherkarani/Wax)
- Caura is a governed shared-memory layer for multi-agent fleets with MCP-native tools, trust tiers, audit trails, tenant isolation and self-improving retrieval. [caura-ai/caura](https://github.com/caura-ai/caura)
- Negotium is a self-hosted node runtime that exposes durable agent topics, queues, memory, wiki, skills, vault secrets and cron schedules through terminal, Telegram and remote workspaces. [maestrojeong/negotium](https://github.com/maestrojeong/negotium)
- AI Fleet Status is a zero-dependency VS Code status-bar monitor that shows whether Codex, Claude Code, Gemini CLI, Hermes or other background agent processes are running. [shubhsaxena2020/ai-fleet-status](https://github.com/shubhsaxena2020/ai-fleet-status)
- Skills Manager provides a local web UI for browsing, searching, enabling, pinning, linking, installing and deleting skills across Hermes, Claude, Codex, Cursor and shared agent directories. [oubuild/skills-manager](https://github.com/oubuild/skills-manager)
