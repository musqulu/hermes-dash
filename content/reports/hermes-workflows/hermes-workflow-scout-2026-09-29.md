# Hermes workflow items worth opening today

- 🔥 Best: Pero is an always-on VPS personal agent runtime with Telegram topics, scheduled tasks, background workflows, and proactive messaging that maps very directly onto Hermes gateway/cron/profile ideas. [perokit/pero](https://github.com/perokit/pero)
- Ralphy is a compact autonomous coding loop with git worktree support, session management, a terminal admin dashboard, and prompt/skills structure worth mining for Hermes unattended coding runs. [KSDaemon/ralphy](https://github.com/KSDaemon/ralphy)
- Agentrove is a self-hosted workspace for orchestrating Claude Code, Codex, Copilot, Cursor, Grok, OpenCode and other agents with personas and ACP-powered sandboxes. [Mng-dev-ai/agentrove](https://github.com/Mng-dev-ai/agentrove)
- Crewplane defines reviewable, resumable coding-agent workflows in Markdown and keeps prompts, stages, gates, handoffs, and outputs on disk for auditability. [crewplaneai/crewplane](https://github.com/crewplaneai/crewplane)
- AbstractGateway is a replay-first HTTP control plane for durable AI runs with command inboxes, append-only ledgers, scheduling, streaming, and multi-client access. [lpalbou/AbstractGateway](https://github.com/lpalbou/AbstractGateway)
- Workflow Toolbox is a Claude Code workflow plugin and TypeScript pattern library for choosing the right orchestration level from single-agent work to deterministic multi-agent flows. [home-dev-lab/workflow-toolbox](https://github.com/home-dev-lab/workflow-toolbox)
- SideKernel is a macOS microVM sandbox designed specifically to make AI coding-agent isolation usable without breaking the normal developer loop. [minoansecurity/sidekernel](https://github.com/minoansecurity/sidekernel)
- Overmux combines tmux terminals, web/mobile UIs, git review surfaces, and plugins into a customizable workspace for humans and coding agents. [richardgill/overmux](https://github.com/richardgill/overmux)
- swe-mux is a Tailscale-enabled terminal multiplexer/control plane for running Claude Code, Codex and other agents side by side with mobile status, reviews, previews and alerts. [jatoran/swe-mux](https://github.com/jatoran/swe-mux)
- withmcp is a host-wide MCP configuration manager that can toggle server groups globally or per project before launching Claude, Codex or another harness. [lava/withmcp](https://github.com/lava/withmcp)
