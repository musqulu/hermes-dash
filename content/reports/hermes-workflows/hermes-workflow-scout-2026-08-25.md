# Hermes workflow items worth opening today

- 🔥 Best: Hive is a local-first workflow engine that turns rough ideas into folder-based agent pipelines for Claude, Codex, Grok and Pi, making it a strong reference for durable Hermes workflow orchestration. [ivankuznetsov/hive](https://github.com/ivankuznetsov/hive)
- kmux is a macOS/Linux terminal workspace for running Claude Code, Codex CLI and Antigravity side-by-side with session resume, usage dashboards and automatic git worktrees. [kkd927/kmux](https://github.com/kkd927/kmux)
- Agent Workflows packages reusable Codex/Claude prompts, helper scripts and AGENTS.md seams for PR batches, CI routing, review triage and audit loops. [shakacode/agent-workflows](https://github.com/shakacode/agent-workflows)
- Agents Commander runs multiple CLI coding agents as a coordinated local-first “Loop” team with full PTY support, scheduling and file-based coordination. [mblua/AgentsCommander](https://github.com/mblua/AgentsCommander)
- dotagents keeps skills, MCP servers, hooks, roles and memory in one audited ~/.agents repo that syncs across Claude Code, Codex, OpenCode, Pi and Hermes. [yourconscience/dotagents](https://github.com/yourconscience/dotagents)
- Axiom adds safety-first routing for Codex and Claude Code actions with explicit scope, authorization, evidence capture and rollback expectations. [wheakerd/axiom](https://github.com/wheakerd/axiom)
- agent-workboard is a small REST server, dashboard and hook kit for preventing multiple Claude Code/Codex/Gemini agents from clobbering the same codebase. [oh-namgyu/agent-workboard](https://github.com/oh-namgyu/agent-workboard)
- Hermes Console is an Android-first private client for self-hosted Hermes Agent with chat, bots, voice and remote control from a phone. [xP3ta/hermes-console](https://github.com/xP3ta/hermes-console)
- Fleetgraph is a Hermes plugin for hierarchical bot organizations, persistent role structure, bounded communication and specialist discovery across profiles. [asmodaydoescoding/fleetgraph](https://github.com/asmodaydoescoding/fleetgraph)
- hermes-remote exposes a local Hermes Agent through an authenticated API, TypeScript client and React hooks so external apps can safely drive it. [in-th3-l00p/hermes-remote](https://github.com/in-th3-l00p/hermes-remote)
