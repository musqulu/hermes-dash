# Hermes workflow items worth opening today

- 🔥 Best: Engraphis is a local-first, inspectable memory layer for coding agents with durable context across sessions and repositories, code-aware recall, bi-temporal history, MCP access and a self-hosted WebUI. [Open Engraphis](https://github.com/Coding-Dev-Tools/engraphis)
- Wolfpack is a self-hosted browser and phone control room for persistent Claude Code, Codex, Gemini, Cursor, Pi and shell terminals over Tailscale. [Open Wolfpack](https://github.com/almogdepaz/wolfpack)
- Storybloq keeps stories, plans, handovers and review evidence beside the code so Claude Code and Codex work can resume across sessions and be followed in a Mac app. [Open Storybloq](https://github.com/Storybloq/storybloq)
- Derbent is an MCP guard layer that records tool-call receipts while centralizing shared memory, approvals and tool routing for multiple coding agents. [Open Derbent](https://github.com/tunahanaliozturk/derbent)
- ArchGraph models architecture, agent intent and long-term memory as one ArchiMate graph exposed through a read/write MCP interface. [Open ArchGraph](https://github.com/derekhu0002/archgraph)
- Lectern runs Claude Code, Codex, Gemini, OpenCode, Aider and Cursor agents on owned machines with control from a terminal dashboard, phone or claude.ai chat. [Open Lectern](https://github.com/JeremiahM37/lectern)
- Clawdline watches existing Claude Code and Codex sessions in tmux or iTerm2 without wrappers, hooks or MCP and lets you answer waiting agents from a local React console or phone. [Open Clawdline](https://github.com/sainteye/clawdline)
- aipager is a minimal Telegram remote control for detached Claude Code sessions, including reading responses, sending prompts, approving permission requests and switching sessions. [Open aipager](https://github.com/dev-aly3n/aipager)
- pagelore stores coding-agent decisions, contracts and bug post-mortems as Markdown pages with BM25F search over CLI or MCP and no server or database. [Open pagelore](https://github.com/Krowli/pagelore)
- SceneScout gives coding agents an MCP-driven exploratory UI testing loop with a structured app view, always-on oracles, network write policy, cross-run memory and gap-checked reports. [Open SceneScout](https://github.com/brunoboto96/SceneScout)
