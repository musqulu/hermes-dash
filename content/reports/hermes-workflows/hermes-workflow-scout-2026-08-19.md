# Hermes workflow items worth opening today

- 🔥 Best: Knownbase is an MCP-backed project-memory layer that stores architecture decisions, debugging discoveries, rejected approaches and handoffs so Claude Code, Codex, Cursor and other agents can retrieve project knowledge across sessions: [Knownbase](https://knownbase.dev/)
- Context Engine is a local “headless IDE” MCP server that gives coding agents LSP-style tools such as outline, jump-to-definition, usages, hover and smart reads instead of forcing them to grep or hallucinate APIs: [Context Engine](https://context-engine.app/)
- Relay is a self-hosted remote cockpit for running Claude Code, Codex, OpenCode and Hermes on a home machine while controlling sessions and swarms from a phone or browser: [elin66alpha/Relay](https://github.com/elin66alpha/Relay)
- singular-lite is a durable multi-agent coding orchestrator with L0/L1/L2 agents, leases, gate audits, state packets and git-worktree isolation that maps closely to Hermes kanban/worktree-worker ideas: [alex-reysa/singular-lite](https://github.com/alex-reysa/singular-lite)
- penguin runs TypeScript-defined coding-agent workflows as detached live processes that can keep working without an open terminal while viewers attach, watch, message and detach: [mikaelweiss/penguin](https://github.com/mikaelweiss/penguin)
- Memanto is a “memory agent” that manages what other agents should keep, expire, conflict-check and share, useful as a design reference for Hermes memory rollups and stale-memory pruning: [moorcheh-ai/memanto](https://github.com/moorcheh-ai/memanto)
- Seahorse proposes an open, Apache-licensed standard for persistent self-evolving LLM-agent memory, worth inspecting for portable memory schema and agent-write patterns: [ssanvi-builds/seahorse](https://github.com/ssanvi-builds/seahorse)
- fx is Vercel’s experimental tiny native coding agent, useful as a minimal reference for an embeddable Unix-like agent CLI rather than a full dashboard-heavy orchestration stack: [vercel-labs/fx](https://github.com/vercel-labs/fx)
- ForgeAI shows a six-stage Product Manager → Architect → Database → Backend → Frontend → DevOps coding pipeline with a live status dashboard, useful as a concrete “agent factory” UI pattern to compare against Hermes dashboards: [AlSh007/Forge-AI](https://github.com/AlSh007/Forge-AI)
- PrismAI combines LangGraph, CRAG retrieval, PR analysis, security scoring and a human-in-the-loop dashboard into a focused autonomous PR-review agent that could inform Hermes review-worker templates: [AGNIHOTRIMAHI/PrismAI](https://github.com/AGNIHOTRIMAHI/PrismAI)
