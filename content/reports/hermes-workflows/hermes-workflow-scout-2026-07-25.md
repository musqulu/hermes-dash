# Hermes workflow items worth opening today

- 🔥 Best: Lucarne is a zero-intrusion mobile control bridge for local Codex, Claude, Grok, or Pi sessions with Telegram/WeChat/Feishu approvals and resume flow: [GitHub](https://github.com/tuchg/Lucarne)
- Entire CLI captures AI-agent coding sessions alongside Git commits, which is directly relevant for Hermes session provenance and searchable “why did this change happen” history: [GitHub](https://github.com/entireio/cli)
- Pro Workflow packages correction-learning memory, parallel worktrees, agent teams, and reusable skills into a Claude Code workflow that maps cleanly to Hermes skills and curator ideas: [GitHub](https://github.com/rohitg00/pro-workflow)
- Claude Code Showcase is a large concrete example repo for hooks, skills, agents, commands, and GitHub Actions that can be mined for Hermes skill and hook patterns: [GitHub](https://github.com/ChrisWiles/claude-code-showcase)
- Claude Night Market collects ready-made plugins for TDD gates, PR workflows, spec-driven development, review, maintenance, context optimization, research, and delegation: [GitHub](https://github.com/athola/claude-night-market)
- OtoDock runs Claude Code and Codex as a team of agents on a server, making it worth studying for persistent multi-agent infrastructure and dashboard ergonomics: [GitHub](https://github.com/OtoDock/oto-dock/)
- Caliper tests Claude Code and Codex skills with pass@k-style reliability checks, a useful pattern for regression-testing Hermes skills and prompts: [GitHub](https://github.com/edonadei/caliper)
- OpenBenchmarks helps agents discover and choose SaaS APIs, which suggests a practical source-discovery layer for Hermes research and implementation agents: [OpenBenchmarks](https://openbenchmarks.com)
- AI-company presents a multi-agent team operating system with lifecycle hooks, persistent teams, task wall, and real-time dashboard ideas to compare against Hermes kanban and gateway workers: [GitHub](https://github.com/CronusL-1141/AI-company)
- Claude Forge bundles agents, commands, skills, and security hooks into an oh-my-zsh-style Claude Code plugin framework, useful as a packaging model for Hermes community extensions: [GitHub](https://github.com/sangrokjung/claude-forge)
