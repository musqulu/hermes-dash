# Hermes workflow items worth opening today

- 🔥 Best: Nightmux is a Telegram-topic control room for Claude Code, Codex, or any terminal agent, with one tmux session per topic plus context-window and 5-hour-limit handling. [GitHub](https://github.com/mmr710/nightmux)
- Cliclaw is a Telegram bot for driving Claude Code, Codex, Pi, and Gemini from a phone with per-agent sessions, response streaming, image attachments, and dangerous-command confirmation gates. [GitHub](https://github.com/choiyounggi/cliclaw)
- SquadCue treats local CLI agent sessions as named workers you can chat with, resume, orchestrate, and gate through web or Telegram approval inboxes. [GitHub](https://github.com/hsienchuc/squadcue)
- Grafana Agent Observability for Hermes is an unofficial Hermes plugin that records LLM calls and tool executions into Grafana’s agent observability flow. [GitHub](https://github.com/alexander-akhmetov/grafana-agento11y-hermes)
- Agent Desktop is a native desktop-automation CLI that exposes OS accessibility trees as structured JSON with deterministic element refs for more reliable GUI agents. [GitHub](https://github.com/lahfir/agent-desktop)
- AiMind is a multi-pane terminal workspace for AI coding CLIs with a shared task and memory MCP server plus swarm orchestration ideas. [GitHub](https://github.com/Ravikiranbantwal/aimind)
- QMesha is an MCP-native governance layer with pre-execution spending limits, auditable decision provenance, and local-first Markdown memory. [GitHub](https://github.com/CHIMERA1B/QMesha)
- localmem-mcp is a new local-first MCP memory server that gives agents persistent private memory without API keys or cloud calls. [GitHub](https://github.com/OpenAgentHQ/localmem-mcp)
- LoopKernel is a local-first loop-engineering kernel for keeping goals, todos, gates, evidence, and quota stable across bounded long-running agent turns. [GitHub](https://github.com/gitstq/loopkernel)
- FleetView is a macOS multi-session dashboard for running Claude Code, Codex, Gemini CLI, or shell PTYs side by side with live usage and cost tracking. [GitHub](https://github.com/bonjiko15/fleetview)
