# Hermes workflow items worth opening today

- 🔥 Best: Graft is a hook-based context layer for Claude Code/Cursor/Codex/Gemini that is worth studying for Hermes codebase-aware tool selection and cached project context. [GitHub](https://github.com/NanoNets/Graft)
- Dynobox is a cross-harness test runner for multi-step agent flows, useful as inspiration for regression tests around Hermes skills, tools, and cron workflows. [GitHub](https://github.com/dynobox/dynobox)
- tmux-agent-switcher is a tmux sidebar for monitoring Claude Code, Codex, and OpenCode agents, directly relevant to multi-agent Hermes worker visibility. [GitHub](https://github.com/Ymirke/tmux-agent-switcher)
- linear-claude-bridge runs Claude Code sessions from Linear issues on your own machine, a good pattern for issue-scoped Hermes agents with local repo context. [GitHub](https://github.com/MPIsaac-Per/linear-claude-bridge)
- mcp-memory combines OKF-formatted long-term agent memories with local SQLite FTS5 search, worth comparing against Hermes memory rollups and MCP exposure. [GitHub](https://github.com/fellowgeek/mcp-memory)
- log-decisions is an agent skill for maintaining an append-only DECISIONS.md journal, a lightweight durable memory pattern for consequential autonomous-agent choices. [GitHub](https://github.com/swe-workflow/log-decisions)
- Neal separates planner, coder, and reviewer roles across configurable providers, a compact reference for Hermes multi-model coding loops. [GitHub](https://github.com/navels/neal)
- Caraka is a thin Telegram bridge that sends tasks to a local coding agent, useful as a minimal comparison point for Hermes gateway task intake. [GitHub](https://github.com/CarakaDev/caraka)
- AIPass is a persistent agent workspace focused on identity, memory, and collaboration, relevant to profile-scoped Hermes agents that should not start from zero. [GitHub](https://github.com/AIOSAI/AIPass)
- Reyn frames agent workflows as constrained, validated, replayable execution, a useful design lens for safer proactive Hermes cron jobs. [GitHub](https://github.com/tya5/reyn)
