# Hermes workflow items worth opening today

- 🔥 Best: agent-bridge is a self-hosted durable runtime for Codex, Claude Code, Cursor, Antigravity and Grok Build workstreams with Telegram or Discord access. [Farstax/agent-bridge](https://github.com/Farstax/agent-bridge)
- cc-connect-next is a privacy-first gateway for driving Claude Code, Codex and twelve other local coding agents from Feishu/Lark with mid-turn steering plus Telegram, Slack and Discord support. [timmyagentic/cc-connect-next](https://github.com/timmyagentic/cc-connect-next)
- mullion-session-manager is a tiled persistent browser dashboard for host-run Claude Code, Codex and OpenCode terminal sessions. [s3ntin3l8/mullion-session-manager](https://github.com/s3ntin3l8/mullion-session-manager)
- skyboy is an agent-agnostic SKILL.md directory that previews, installs and ships reusable skills across Claude, ChatGPT, Cursor and Gemini CLI. [aijadugar/skyboy](https://github.com/aijadugar/skyboy)
- agent-relay packages a neutral implement → self-review → cross-review SKILL.md pipeline that can be adapted across Cursor, Antigravity, Codex and Claude-style agents. [tranthethang/agent-relay](https://github.com/tranthethang/agent-relay)
- leo is a CLI for setting up Claude Code agents as persistent proactive assistants with Telegram integration and cron scheduling. [blackpaw-studio/leo](https://github.com/blackpaw-studio/leo)
- open-primeagent explores a persistent Python runtime, persistent subagents and a continual harness around existing Claude Code, Codex and OpenCode workflows. [softkleenex/open-primeagent](https://github.com/softkleenex/open-primeagent)
- fountain exposes Claude Code, Codex and Gemini CLI as an HTTP API with one sandbox per agent session. [BinaryBourbon/fountain](https://github.com/BinaryBourbon/fountain)
- oboete is an early local-first continuity layer aimed at keeping Claude Code and Codex memory portable across sessions. [ojungo69/oboete](https://github.com/ojungo69/oboete)
- skillsmith-web is a browser demo for linting and security-scanning Claude Agent SKILL.md files before installing or sharing them. [Larslllllll/skillsmith-web](https://github.com/Larslllllll/skillsmith-web)
