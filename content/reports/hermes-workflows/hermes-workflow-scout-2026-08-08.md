# Hermes workflow items worth opening today

- 🔥 Best: Bernstein is a deterministic orchestrator for CLI coding agents that runs Claude Code, Codex, Gemini CLI and many others in per-task git worktrees with replayable coordination and signed audit lineage. [sipyourdrink-ltd/bernstein](https://github.com/sipyourdrink-ltd/bernstein)
- MatrixClaw is an always-on local agent runtime with Terminal and Telegram control, durable SQLite memory, MCP tools, approvals, scheduled tasks and Claude Code/Codex subagents. [Suren878/matrixclaw](https://github.com/Suren878/matrixclaw)
- AgEnD turns Telegram into a multi-agent fleet daemon for Claude Code, Gemini CLI, Codex and OpenCode with cross-instance collaboration. [songsid/AgEnD](https://github.com/songsid/AgEnD)
- Kody packages portable MCP-hosted memory, keys, code and automations for an assistant across multiple agent clients on Cloudflare Workers. [kentcdodds/kody](https://github.com/kentcdodds/kody)
- memo is a local-first persistent memory layer for Claude Code, Codex, Cursor and other MCP clients using Markdown as source of truth, hybrid search and contradiction checks. [jagoff/memo](https://github.com/jagoff/memo)
- Grove models coding-agent orchestration as a recursive tree of parent and child sessions, with worktree-per-task isolation and an attention inbox. [AnkushinDaniil/grove](https://github.com/AnkushinDaniil/grove)
- Agent OS LangGraph is a coding-agent orchestrator with human-in-the-loop gates, SQLite resume, tiered routing, MCP support and Claude/Codex subscription backends. [simon-aibc/agent-os-langgraph](https://github.com/simon-aibc/agent-os-langgraph)
- claude-mission-control is a local-first web dashboard for supervising an autonomous Claude coding agent with task boards, live activity, plan approvals and permission prompts. [kapvadym/claude-mission-control](https://github.com/kapvadym/claude-mission-control)
- MemoryWhale records commands, outputs, errors and working fixes into local SQLite and exposes them over MCP for developer-agent recall. [wuisabel-gif/MemWhale](https://github.com/wuisabel-gif/MemWhale)
- Agentic Cloud Computer is a Telegram-first service pattern where each Claude Code agent gets its own persistent machine and chat, useful as a product reference for remote Hermes workers. [agenticcloudcomputer.com](https://agenticcloudcomputer.com/)
