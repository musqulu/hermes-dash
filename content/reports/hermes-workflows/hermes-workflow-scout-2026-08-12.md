# Hermes workflow items worth opening today

- 🔥 Best: amux is a local-first tmux-native control plane for running, monitoring and scheduling dozens of Claude Code, Codex and Gemini workers from a web dashboard or phone. [mixpeek/amux](https://github.com/mixpeek/amux)
- ai-agents-skills packages reusable kanban, autonomous timed-runner, git-flow, QA-gate and Telegram-notification skills as a shared plugin for Claude Code, Codex, Cursor and Hermes. [Xakki/ai-agents-skills](https://github.com/Xakki/ai-agents-skills)
- nightmux maps Telegram forum topics to tmux sessions for Claude Code, Codex or any terminal agent, with context-window and rate-limit handling for overnight runs. [mmr710/nightmux](https://github.com/mmr710/nightmux)
- Opendray is a self-hosted gateway for Claude Code, Codex, Antigravity, Grok Build and OpenCode with shared local memory plus web, mobile and chat control surfaces. [Opendray/opendray](https://github.com/Opendray/opendray)
- agent-relay lets Telegram or Lark users choose a workspace, steer local Codex sessions, approve actions, review code and exchange files or screenshots. [zwx1127/agent-relay](https://github.com/zwx1127/agent-relay)
- Prism Coder is a local-first MCP memory server for coding agents with persistent handoff notes, associative recall, drift detection and offline model routing. [dcostenco/prism-coder](https://github.com/dcostenco/prism-coder)
- mehmory uses hook-enforced Markdown files in Git as a simple model-maintained memory wiki for Claude Code and Codex without embeddings or an MCP server. [elderfo/mehmory](https://github.com/elderfo/mehmory)
- CommitLore stores durable decision records in Git and injects still-active constraints or rejected alternatives before Claude Code, Codex or Cursor edits files. [MongLong0214/commitlore](https://github.com/MongLong0214/commitlore)
- Fleetpost is a serverless mailbox convention for coordinating independent coding agents across sleeping machines through any rclone-backed shared folder. [StanimirTenev/fleetpost](https://github.com/StanimirTenev/fleetpost)
- 5dive Plugins shows a marketplace-style Telegram bridge pattern for Claude Code plus Codex and Grok runtime forks, including inline permission approval for Codex. [5dive-ai/5dive-plugins](https://github.com/5dive-ai/5dive-plugins)
