# Hermes workflow items worth opening today

- 🔥 Best: Talos is a self-hosted terminal/Telegram agent with Claude/Codex workers, live activity, and a deterministic permission kernel that is directly relevant to safer Hermes remote execution. [talos-kernel/Talos](https://github.com/talos-kernel/Talos)
- TraceDecay gives coding agents local semantic code intelligence, project memory, and workflow context over Rust/tree-sitter/MCP so they can answer with fewer token-heavy file scans. [ScriptedAlchemy/tracedecay](https://github.com/ScriptedAlchemy/tracedecay)
- Buildd is an MCP-native task queue where agents claim scheduled or dashboard-created tasks, branch, code, open PRs, and reuse shared memory across attempts. [buildd-ai/buildd](https://github.com/buildd-ai/buildd)
- Friday is a self-hosted persistent cognitive memory layer for coding agents that stores architecture decisions, schemas, and preferences across Claude/Cursor/Codex-style sessions. [friday-memory/friday](https://github.com/friday-memory/friday)
- Ryu Calendar shows agent and workflow schedules as month/week/day/agenda views with past run history and new automation creation, a clean UI reference for Hermes cron visibility. [amajorai/ryu-calendar](https://github.com/amajorai/ryu-calendar)
- AutoBot is a self-improving harness for long multi-application knowledge-work tasks where successful workflow repairs become durable upgrades to future runs. [demeyer1/Autobot](https://github.com/demeyer1/Autobot)
- Toolcraft is an open-source starter kit and UI library for building small AI-assisted design apps with Codex, Claude, or Cursor, useful as a template for agent-built micro-tools. [pixel-point/toolcraft](https://github.com/pixel-point/toolcraft)
- AUTOPILOT wraps Claude Code in a gated autonomous repo-improvement loop with backups, codebase understanding, verified changes, and a local dashboard. [M-A-S-T-E-R-M-I-N-D/AUTOPILOT](https://github.com/M-A-S-T-E-R-M-I-N-D/AUTOPILOT)
- Skillsync is pitching portable AI chat sessions across coding agents, a useful product reference for Hermes session export/import and cross-agent handoff UX. [Skillsync](https://skillsync.com)
- Gotincan’s “multiplayer mode for AI agents” is worth scanning as a collaboration pattern for shared agent rooms and human/agent coordination. [Gotincan](https://gotincan.com/)
