# Hermes workflow items worth opening today

- 🔥 Best: Proliferate is an open-source AI IDE for running Claude Code, Codex, OpenCode, Grok and other coding agents in parallel with isolated git worktrees, review state and reusable workflows. [proliferate-ai/proliferate](https://github.com/proliferate-ai/proliferate)
- Open Second Brain is an Obsidian-native memory layer for Hermes Agent that stores preferences, evidence, audit trails and nightly dream-rollup outputs as plain Markdown plus MCP/CLI tools. [itechmeat/open-second-brain](https://github.com/itechmeat/open-second-brain)
- SharkBay is a macOS multi-agent workbench for Claude Code, Codex, Gemini, Kiro and other coding CLIs with hook-based status, project terminals, browser context, git overview and Telegram remote control. [SharkUI/SharkBay](https://github.com/SharkUI/SharkBay)
- telegram-ai-bridge coordinates Claude Code, Codex, Agy and Kimi bots inside Telegram groups through an A2A-inspired envelope with loop suppression and owner-gated self-hosted routing. [AliceLJY/telegram-ai-bridge](https://github.com/AliceLJY/telegram-ai-bridge)
- Bastet Agent OS is a local-first control plane for Claude Code, Codex, Grok, Antigravity and Hermes teams with gated workflows, metering, append-only audit logs and team memory. [yamantaka520/Bastet-Agent-OS](https://github.com/yamantaka520/Bastet-Agent-OS)
- TaroCub is a Feishu/Lark-first local bridge that keeps Codex, Claude Code, Kimi Code and Antigravity sessions durable with files, cron, audit logs, ASR and optional Telegram compatibility. [cloveric/tarocub](https://github.com/cloveric/tarocub)
- chat-recall indexes Claude Code, Gemini CLI, Codex, OpenCode and Antigravity transcripts into one searchable redacted history and exposes recall through MCP tools. [munhq/chat-recall](https://github.com/munhq/chat-recall)
- AnkaLoop packages a coding-agent runtime with built-in tools, subagents, skills, persistent context, MCP/ACP, hooks, automation and Telegram access in one Python package. [tao12345666333/ankaloop](https://github.com/tao12345666333/ankaloop)
- Visionary is a zero-build local mission-control dashboard that dispatches kanban tasks across OpenClaw, Claude Code, Hermes, Codex, Cursor, Gemini and Ollama with SQLite state and failover. [ZombieDuckling/visionary](https://github.com/ZombieDuckling/visionary)
- Agent Mesh gives multi-agent software projects a durable local workbench for requests, decisions, handoffs, approvals and completed work that survive chat boundaries. [cbalgeman/agent-mesh](https://github.com/cbalgeman/agent-mesh)
