# Hermes workflow items worth opening today

- 🔥 Best: HAR is an open agent harness that runs Claude Code, Cursor and Codex workers in isolated git worktrees with deterministic validation, MCP access and observability. [os-factory/har](https://github.com/os-factory/har)
- StateRoot keeps project goals, plans, memory, skills, rules and sessions portable across Claude Code, Codex, Cursor, Kimi Code, Pi and other coding agents. [CognizTech/stateroot](https://github.com/CognizTech/stateroot)
- Membrane acts as a context control plane that assembles the smallest useful set of code, rules, decisions and memory for a task, with receipts for what entered context and why. [Orthic-Labs/Membrane](https://github.com/Orthic-Labs/Membrane)
- MeMesh is a local SQLite-backed MCP and CLI memory layer that captures coding-agent work, injects relevant recall at action time and checks contradictions. [PCIRCLE-AI/memesh](https://github.com/PCIRCLE-AI/memesh)
- Cetus wraps Claude Code, Codex and other agent runtimes in a macOS desktop layer with scheduled runs, screen context, global quick reply and a shared review board. [drewnekota/cetus](https://github.com/drewnekota/cetus)
- TerMinal is a macOS app that hosts real Claude Code, Codex and Hermes-compatible agent CLIs with backlog ownership, scheduling, review surfaces and cost ledgers. [trevormil/TerMinal](https://github.com/trevormil/TerMinal)
- Urdr is a fresh Telegram, Feishu, web and CLI terminal layer for driving Claude Code and Codex through one orchestration core with provider profiles and tool scopes. [plfccc/urdr](https://github.com/plfccc/urdr)
- SocialClaw packages social-post scheduling as both a CLI and OpenClaw skill, useful as a model for Hermes skills that turn agent output into queued cross-platform publishing. [ndesv21/socialclaw](https://github.com/ndesv21/socialclaw)
- runyaml defines shell and coding-agent DAGs in YAML, streams node outputs through downstream steps and exposes a debug dashboard for plan-implement-validate workflows. [alifanov/runyaml](https://github.com/alifanov/runyaml)
- auto-bug-fix is a deterministic Jira-to-GitLab scheduler that hands each bug to Codex, Claude Code, Cursor or Kiro while keeping the fix workflow JSON-first and dry-run guarded. [fatecannotbealtered/auto-bug-fix](https://github.com/fatecannotbealtered/auto-bug-fix)
