# Hermes workflow items worth opening today

- 🔥 Best: MAMA OS is a local-first messenger-facing memory/work runtime for Claude Code, Codex and MCP agents, with scoped cases, receipts, bounded workers and Telegram/Slack/Discord front doors. [jungjaehoon-lifegamez/MAMA](https://github.com/jungjaehoon-lifegamez/MAMA)
- agentacct reads local Claude Code, Codex, OpenCode and Hermes logs to produce task-level work receipts with tools used, files changed, tests run, time and token cost. [mikehasa/agentacct](https://github.com/mikehasa/agentacct)
- Hermes Agents Forge is a Hermes-native bootstrap repo for interviewing a user, designing specialist profiles, and provisioning isolated multi-profile teams for repeatable workflows. [juliench82/hermes-agents-forge](https://github.com/juliench82/hermes-agents-forge)
- Hermes Dev Workflow is a portable Hermes multi-profile Kanban pipeline that ingests GitHub issues, dispatches coder/reviewer agents, consolidates PRs and runs QA checks. [baijulabs/hermes-dev-workflow](https://github.com/baijulabs/hermes-dev-workflow)
- APE turns Claude Code and Codex CLI into auditable Plan → Build → Ship runs where scheduler-owned stages, receipts and gates decide whether work can advance. [AAWWCC/ape](https://github.com/AAWWCC/ape)
- Pixcode is a self-hosted control plane for Claude Code, Codex, Gemini CLI, Cursor, Qwen and OpenCode with chat, files, shell, Git, orchestration, Telegram, MCP and API automation. [alicomert/pixcode](https://github.com/alicomert/pixcode)
- Tokdash is a local token, quota and cost dashboard for AI coding tools that could inform Hermes Dash usage analytics and quota-reset monitoring. [JingbiaoMei/Tokdash](https://github.com/JingbiaoMei/Tokdash)
- Agent Sandbox runs coding agents inside throwaway KVM microVMs with a dashboard, live streaming, script/IDE starts and PR return flow. [HatriGt/agent-sandbox](https://github.com/HatriGt/agent-sandbox)
- Hermedian embeds Hermes Agent directly inside Obsidian so a vault becomes the working directory for file edits, search, bash and multi-step agent workflows. [yrarjun59/hermedian](https://github.com/yrarjun59/hermedian)
- OpenClaw Memoria is a local multi-agent memory layer with private per-agent memories and governed sharing for Claude Code, Codex, OpenClaw and MCP agents. [Primo-Studio/openclaw-memoria](https://github.com/Primo-Studio/openclaw-memoria)
