# Hermes workflow items worth opening today

- 🔥 Best: TelegramAgentBot maps each Telegram forum topic to a persistent tmux window for Codex CLI or Claude Code, which is a clean reference for topic-scoped mobile control without replacing the terminal. [Pigbibi/TelegramAgentBot](https://github.com/Pigbibi/TelegramAgentBot)
- Hermit Agent bootstraps a Telegram-connected Claude Code or Codex host with persona, long-term memory, scheduler and browser automation from one command. [swaylq/hermit-agent](https://github.com/swaylq/hermit-agent)
- AI CLI Observability packages Codex, Claude Code and Gemini CLI telemetry into a self-hosted OpenTelemetry plus Grafana stack for tokens, cost, errors, tool activity and traces. [TheophileDiot/ai-cli-observability](https://github.com/TheophileDiot/ai-cli-observability)
- Caprock is a local dashboard for live Claude Code session activity, cost-per-repo tracking and loop alerts with no telemetry. [dspv/caprock](https://github.com/dspv/caprock)
- agent-backbone gives terminal coding agents persistent sessions, inter-agent communication, delegation channels and GitHub Issues-backed task lists without putting coordination files in the repo. [eandualem/agent-backbone](https://github.com/eandualem/agent-backbone)
- Open Run schedules Claude Code, Codex, Grok and other local coding agents as machine-local cron jobs without hosted runners or API keys. [dennisadriaans/openrun](https://github.com/dennisadriaans/openrun)
- AutoSpec turns vague coding intent into durable specs, GitHub issue trees, validation gates, PR evidence and project memory for Claude Code, Codex and OpenCode workflows. [berlinguyinca/autospec](https://github.com/berlinguyinca/autospec)
- Memplex is a multi-agent long-term memory layer for Codex, Claude Code, OpenClaw and Hermes with pre-turn recall, post-turn capture and context compaction. [articultur/memplex](https://github.com/articultur/memplex)
- Cortex is a cross-platform persistent-memory MCP server for Codex, Gemini CLI, Claude Code and other local MCP hosts using local-first consolidation and retrieval. [cdeust/Cortex](https://github.com/cdeust/Cortex)
- Continuum captures Claude Code sessions, syncs context across machines, adds durable MCP-backed memory and exposes parallel-agent communication through an API and UI. [MehdiMohseni82/continuum](https://github.com/MehdiMohseni82/continuum)
