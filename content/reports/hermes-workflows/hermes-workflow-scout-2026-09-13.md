# Hermes workflow items worth opening today

- 🔥 Best: Novgraph is a persistent codebase knowledge graph that agents update as they work, with stale-code deranking and claimed large token savings for Claude Code/Codex/OpenCode-style workflows. [Novaya-AI/novgraph](https://github.com/Novaya-AI/novgraph)
- Sorify is an open-source pattern for letting AI manage Playwright automations, useful for making Hermes browser workflows more repeatable than free-form page driving. [rakutentech/sorify](https://github.com/rakutentech/sorify)
- Aiope packages an on-device Android agent with terminal, browser, SSH, and MCP support, a good reference for mobile-first agent control surfaces. [XNet-NGO/aiope](https://github.com/XNet-NGO/aiope)
- Gitoza is a git-native task-management layer for local coding agents that could inspire a lighter alternative path beside MCP-heavy kanban orchestration. [Gitoza](https://gitoza.com/)
- Usero MCP feeds real user feedback into coding agents through MCP, a practical pattern for closing the loop between shipped work and future agent tasks. [Usero MCP docs](https://usero.io/docs/mcp)
- MaruCheck offers independent QA for AI-generated code, useful as a separate verification gate after Hermes or coding-agent runs. [Kidus-M/MaruCheck](https://github.com/Kidus-M/MaruCheck)
- Lumae is a macOS screen-demo recorder designed so agents can edit recordings over MCP, a useful adjacent workflow for agent-generated demos and changelogs. [Lumae](https://lumae.app)
- Decispher’s Show HN write-up describes an engineering context and memory plane with PR handoffs, branch stories, sandboxed worker agents, and LongMemEval-style measurement ideas. [Show HN: Decispher](https://news.ycombinator.com/item?id=49509142)
- Stend is a small sharing surface for outputs an agent produced, useful as inspiration for lightweight “agent artifact handoff” UX. [Stend](https://stend.sh)
