# Hermes workflow items worth opening today

- 🔥 Best: Scarf is a native macOS/iOS companion for Hermes itself with chat, sessions, memory, cron, MCP, multi-server SSH, and dashboard visibility that maps directly onto Hermes desktop/operator UX ideas: https://github.com/awizemann/scarf
- OtoDock is a self-hosted platform for running Claude Code and Codex as a coordinated team on your server, useful as a reference for durable multi-agent infrastructure and BYO-subscription agent routing: https://github.com/OtoDock/oto-dock
- Agentic Orchestrator is a terminal TUI for launching multiple coding-agent tracks in parallel through research, planning, implementation, review, and PR flow: https://github.com/doordash-oss/agentic-orchestrator
- OneCLI is an open-source credential gateway/vault designed to let agents use services without exposing raw secrets, relevant to safer Hermes tool execution and gateway integrations: https://github.com/onecli/onecli
- MWE-MCP is a self-hosted Markdown-wiki memory server with per-fragment ACLs and overnight organization, worth studying for agent memory rollups and shared memory governance: https://github.com/Fr4nZ82/mwe-mcp
- Shipmates packages Claude Code sub-agents and slash-command workflows that drive a GitHub issue toward a reviewed CI-green PR, a concrete pattern Hermes could adapt for issue-to-PR automation: https://github.com/saman-mb/shipmates
- Tusk turns a repo into a local SQLite-backed work system with isolated worktrees, verifiable criteria, review, observability, and autonomous workflows for coding agents: https://github.com/gioe/tusk
- Vigil is an evidence-gated research harness for Claude Code whose Stop-hook blocks premature completion until task evidence exists on disk, a useful guardrail idea for Hermes scouting and long-running research jobs: https://github.com/M2artiD/vigil
- Agentic Workflow Kit provides tracker-driven, spec-first delivery for Claude Code and Codex with declarative PR/merge policy and an optional autonomous orchestrator: https://github.com/aryeko/agentic-workflow-kit
- GPTMe remains a strong terminal-agent reference for persistent autonomous agents with local tools, web browsing, and code execution that can be customized into user-specific workflows: https://github.com/gptme/gptme
