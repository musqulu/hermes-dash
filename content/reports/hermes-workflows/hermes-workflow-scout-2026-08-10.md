# Hermes workflow items worth opening today

- 🔥 Best: Pocket Agent is a single-user Telegram remote for Claude Code and Codex tmux sessions with an approval tap before every mutating action. [trofimyukdev/pocket-agent](https://github.com/trofimyukdev/pocket-agent)
- CodexClaw is a Telegram bot for Claude Code and Codex CLI with MCP routing, multi-agent orchestration, cron jobs, and access controls. [MackDing/CodexClaw](https://github.com/MackDing/CodexClaw)
- Agent Connect is middleware for triggering Claude Code, Cursor, or Codex from Slack or Telegram and streaming project-bound work back into the chat. [Capsbharg/agent-connect](https://github.com/Capsbharg/agent-connect)
- GoodMemory is a local-first auditable memory layer for apps and coding agents with MCP, HTTP, TypeScript, and Python interfaces. [hjqcan/GoodMemory](https://github.com/hjqcan/GoodMemory)
- sym-mesh-channel lets Claude Code and Codex sessions exchange peer signals in real time through an MCP channel instead of polling shared notes. [sym-bot/sym-mesh-channel](https://github.com/sym-bot/sym-mesh-channel)
- memgw is a shared SQLite and FTS5 long-term memory gateway for Claude Code, Codex CLI, opencode, and any MCP client. [holetexvn/memgw](https://github.com/holetexvn/memgw)
- agentburn is a local zero-dependency profiler for Claude Code, OpenClaw, and Hermes Agent costs across chats, cron jobs, helpers, loops, and retries. [Socialpranker/agentburn](https://github.com/Socialpranker/agentburn)
- telecodex uses Telegram as a topic-aware remote interface for local Codex CLI sessions with attachment handling and SQLite access controls. [sarthaks5978/telecodex](https://github.com/sarthaks5978/telecodex)
- C3 bridges one Telegram forum topic per project to already-running Claude Code, Codex, Claude Desktop, Grok Build, or Antigravity sessions with voice notes and tappable permission prompts. [andrometiq/c3](https://github.com/andrometiq/c3)
- MuxPager is a tmux workspace plus private Telegram topic bridge for keeping Codex and Claude agents reachable from a phone while they run on an always-on server. [Daniel-T-S-Adams/MuxPager](https://github.com/Daniel-T-S-Adams/MuxPager)
