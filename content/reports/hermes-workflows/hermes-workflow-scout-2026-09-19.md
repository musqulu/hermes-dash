# Hermes workflow items worth opening today

- 🔥 Best: FlowBoard is a local-first project-management and persistent-context layer for OpenClaw, Claude Code, Codex, Cursor, and multi-agent coding workflows. [Open FlowBoard](https://github.com/rasimme/FlowBoard)
- Agent Bridge is a self-hosted runtime for keeping Codex, Claude Code, Cursor, Antigravity/Agy, and Grok Build workstreams durable from Telegram or Discord. [Open Agent Bridge](https://github.com/Farstax/agent-bridge)
- TG Agent Gateway maps Telegram forum topics to isolated Claude Code, Codex, and Antigravity sessions, which is directly relevant to topic-scoped agent UX. [Open TG Agent Gateway](https://github.com/F4RD1N/tg-agent-gateway)
- DorkOS is a self-hosted mission-control app for Claude Code, Codex, and OpenCode with session visibility, approvals, and scheduling. [Open DorkOS](https://github.com/dork-labs/dorkos)
- Nightmux is a Python-stdlib Telegram topic controller for tmux-based agent sessions with context-window and lockout handling. [Open Nightmux](https://github.com/mmr710/nightmux)
- Aide packages spec-driven development for AI coding assistants into specs, skills, and a dashboard that runs them. [Open Aide](https://github.com/ragnarwestad/aide)
- TokenTelemetry is a local dashboard for tracking tokens, sessions, tool calls, and reasoning across Hermes Agent, Claude Code, Antigravity CLI, and Codex. [Open TokenTelemetry](https://github.com/semyonfox/tokentelemetry)
- Forja turns Claude Code into a small autonomous software team with a runner, ten-role crew, independent reviewer, and live dashboard. [Open Forja](https://github.com/nunomarques97/forja)
- HarnessTrajectory renders local coding-agent transcripts from Claude Code, Codex, Kimi Code, Grok Build, Devin CLI, and pi as turn-by-turn trajectories with timing and token data. [Open HarnessTrajectory](https://github.com/Demogorgon314/HarnessTrajectory)
- CrewMux runs Claude Code, Codex, Grok, and other agent CLIs side by side in tmux while connecting them through one MCP bridge. [Open CrewMux](https://github.com/wasuza12345/crewmux)
