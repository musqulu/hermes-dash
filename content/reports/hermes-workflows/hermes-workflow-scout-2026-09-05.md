# Hermes workflow items worth opening today

- 🔥 Best: spectoflow is an agent-agnostic spec-driven development framework with a real-time local control plane for Claude Code, Copilot CLI, Codex, Cursor and Gemini workflows. [georgesmomo/spectoflow](https://github.com/georgesmomo/spectoflow)
- Sidekick Agent Hub combines a VS Code assistant and terminal TUI for watching Claude Code, OpenCode and Codex sessions with token, cost and context tracking. [cesarandreslopez/sidekick-agent-hub](https://github.com/cesarandreslopez/sidekick-agent-hub)
- ChatMux wraps existing tmux-backed Claude Code, Codex, OpenCode, Cursor and other agent sessions in one self-hosted web terminal interface. [devswha/chatmux](https://github.com/devswha/chatmux)
- Agent Deck is a cross-platform TUI command center for launching and supervising Claude, Gemini, OpenCode, Codex and other terminal coding agents. [asheshgoplani/agent-deck](https://github.com/asheshgoplani/agent-deck)
- agentmux coordinates Claude Code and Codex across tmux panes with Discord ChatOps, durable queues, structured logs, file/media handling and stuck-session recovery. [adelost/agentmux](https://github.com/adelost/agentmux)
- Open Agent View is an open-source dashboard for seeing active coding-agent runs, human-intervention points and status across many harnesses plus plain terminal sessions. [xhluca/open-agent-view](https://github.com/xhluca/open-agent-view)
- Haifa Agent is a Java/Spring agent runtime focused on durable runs, frozen definitions, checkpoints, policy, memory, tools, skills and MCP for production-style agent products. [haifa-agent/haifa-agent](https://github.com/haifa-agent/haifa-agent)
- dsh-cc ports Claude Code-style skills, agents, hooks, permissions, slash commands, MCP, memory, subagents and worktrees onto the DeepSeek Harness runtime. [jianxx/dsh-cc](https://github.com/jianxx/dsh-cc)
- Zibby Skills packages reusable MCP/tool modules for workflow nodes, including GitHub, GitLab, Sentry, Slack, Jira, Notion, browser, datasets and memory. [ZibbyDev/skills](https://github.com/ZibbyDev/skills)
- Aura is a production SRE agent platform with specialist agents, guardrails, APIs, state management, streaming and failure handling for incident-investigation workflows. [mezmo/aura](https://github.com/mezmo/aura)
