# Hermes workflow items worth opening today

- My Agent Team is a Bun/Next/SQLite multi-agent runtime with switchable child-process agent backends, plugin hooks, run pooling, SSE visibility, and web/Feishu operator surfaces worth mining for Hermes workspace orchestration ideas. [Chengchcc/my-agent-team](https://github.com/Chengchcc/my-agent-team)
- Agent Workflow is a cross-agent memory/workflow substrate that bootstraps AGENTS.md-style project context for Claude Code, Codex, Cursor and similar agents, directly relevant to Hermes skill and memory rollup design. [sabaiway/agent-workflow](https://github.com/sabaiway/agent-workflow)
- better-tg-cli exposes Telegram account search, send and bot-button interactions as a terminal and MCP surface, useful for Hermes Telegram workflows that need to inspect real chat state beyond bot-only APIs. [TheVilfer/better-tg-cli](https://github.com/TheVilfer/better-tg-cli)
- Chibi is a self-hosted asynchronous Telegram companion that orchestrates multiple AI providers, tools and sub-agents, making it a good reference for long-running chat-first agent task execution. [s-nagaev/chibi](https://github.com/s-nagaev/chibi)
- telegram-agent-bus uses a Telegram group as a no-ports, no-VPN task/ACK/result bus between agents on different machines, a simple pattern Hermes could adapt for lightweight cross-device coordination. [tonydzi/telegram-agent-bus](https://github.com/tonydzi/telegram-agent-bus)
- Apollo is a local-first personal agent platform that decomposes goals into practices, projects, habits, metrics, scheduled reviews, MCP tools and memory, which maps well to proactive Hermes goal loops. [kakalition/apollo](https://github.com/kakalition/apollo)
- Squads CLI packages multi-role AI ops teams with shared goals, persistent memory, verifier roles and a dashboard, useful as a comparison point for Hermes kanban/profile-based multi-agent work. [agents-squads/squads-cli](https://github.com/agents-squads/squads-cli)
- pTask is a single-binary Rust task manager with CLI, TUI, Telegram, HTTP API, MCP surface, recurrence, DAG dependencies, FTS and review flows, making it a strong model for agent-native task infrastructure. [puretensor/ptask](https://github.com/puretensor/ptask)
- n8n AI Agents collects importable workflows for a Telegram voice assistant, MCP tool-calling agent, Slack bot and LLM ETL pipeline, giving concrete node-level automation patterns to translate into Hermes cron/gateway recipes. [Hariharan17194/n8n-ai-agents](https://github.com/Hariharan17194/n8n-ai-agents)
- Autonomous Email Agent shows a LangGraph Gmail assistant with triage routing, human approval, preference memory, cron ingestion and an ops dashboard, useful for designing safe Hermes proactive inbox agents. [git-bonda108/autonomous-email-agent-langgraph](https://github.com/git-bonda108/autonomous-email-agent-langgraph)
