# Hermes workflow items worth opening today

- 🔥 Best: Hope Agent is a cross-device desktop/headless agent with memory, autonomous goals, dynamic multi-agent workflows, and NAS/cloud service mode that maps well to Hermes always-on profile orchestration: https://github.com/shiwenwen/hope-agent
- IVA is a one-command self-hosted Telegram assistant that remembers everything and helps run daily life, useful as a compact reference for Hermes Telegram memory UX: https://github.com/smixs/iva
- Pi Dispatch runs a coding agent as a durable service triggered by cron, GitHub issues, PRs, or on-demand jobs with queueing, spend caps, containers, and an admin panel: https://github.com/edgehero/pi-dispatch
- OpenHermit packages fleet deployment for AI agents with durable state, sandboxed execution, scale management, and channel-based control surfaces: https://github.com/HCF-STUDIOS/openhermit
- CorvinOS explicitly connects Claude Code, Codex, or Hermes Agent to Discord, Telegram, WhatsApp, Slack, and Email as a self-hosted agentic OS: https://github.com/CorvinLabs/CorvinOS
- OpenLoomi is an open-source attention agent that connects work tools, understands current context, and tells the user what needs attention and why: https://github.com/melandlabs/openloomi
- Orloj defines agents, tools, schedules, routing, and policies as YAML, making it a useful infrastructure-as-code reference for Hermes cron and multi-agent governance: https://github.com/OrlojHQ/orloj
- Animaworks explores organization-as-code for autonomous agents with brain-inspired memory that grows, consolidates, and forgets across Claude, Codex, Gemini, Cursor, and Ollama: https://github.com/xuiltul/animaworks
- Vectimus is a Cedar-based deterministic policy engine that intercepts coding-agent actions before execution, relevant to safer Hermes approvals and tool governance: https://github.com/vectimus/vectimus
- Taskhub for StickS3 is a tiny hardware dashboard for monitoring local AI agent tasks from a Mac, a fun reference for ambient Hermes cron/agent status displays: https://github.com/sheepxux/Taskhub-for-StickS3
