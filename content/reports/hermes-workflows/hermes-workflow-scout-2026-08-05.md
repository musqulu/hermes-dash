# Hermes workflow items worth opening today

- 🔥 Best: OtoDock shows a server-side pattern for running Claude Code and Codex as a coordinated agent team, which maps well to Hermes multi-profile/worktree orchestration. https://github.com/OtoDock/oto-dock/
- Tuneloop is a local CLI for analyzing coding-agent session transcripts, useful as inspiration for Hermes session analytics and memory rollups. https://github.com/tuneloop/tuneloop
- Frontend-VisualQA gives coding agents a visual verification loop for UI work, directly relevant to autonomous build-and-check workflows. https://github.com/yutori-ai/frontend-visualqa
- OpenLegion is an agent-fleet platform with container isolation and a vault proxy, worth mining for safer long-running Hermes worker infrastructure. https://www.openlegion.ai
- Claude Memory implements hook-injected local recall with BM25/vector search, a practical pattern for profile-scoped memory without trusting the database as source of truth. https://github.com/ZacTallberg/claude-memory
- Mary Code packages a fail-closed approval gate and workflow skill for Claude Code, useful for Hermes dangerous-action policy and irreversible-command UX. https://github.com/mary-jeon/mary-code
- Autonomous Agentic Research Swarm uses the repo itself as shared memory for multi-agent research, a simple model for durable research state and provenance. https://github.com/AysajanE/autonomous-agentic-research-swarm
- Dispatcher focuses on running coding agents as a team with worktree and tmux orchestration, close to Hermes spawned-agent coordination needs. https://github.com/noamsto/dispatcher
- Agent Odometer is a local desktop dashboard for Codex and Claude Code usage, relevant to Hermes cost/session/token observability. https://github.com/ekalb81/agent-odometer
- Boring Orchestrator centralizes defining, scheduling, launching, and monitoring Claude Code and Codex agents, useful for thinking about a Hermes agent-control dashboard. https://github.com/danielpdmestone9638/boring-orchestrator-agent-hub
