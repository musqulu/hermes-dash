# Hermes workflow items worth opening today

- 🔥 Best: AionUi is a local 24/7 coworking UI explicitly supporting Hermes Agent, Claude Code, Codex and OpenClaw, useful as a reference for multi-agent dashboards and assistant customization. https://github.com/iOfficeAI/AionUi
- MulmoTerminal is a tmux-backed browser terminal grid for running multiple Claude Code/Codex agents in parallel with worktree isolation and “needs you” notifications. https://github.com/receptron/mulmoterminal
- Hunch is a local-first engineering-memory layer that records decisions, constraints and bug history as a git-native graph exposed to coding agents through MCP. https://github.com/davesheffer/hunch
- Iterion is an experimental declarative control plane for agent workflows using readable `.bot` files with chains, judges, routers, human gates, parallel branches and budget caps. https://github.com/SocialGouv/iterion
- Roundtable is a local MCP server that lets one coding assistant delegate work to Claude Code, Codex, Gemini, Cursor and other agents with shared project context. https://github.com/askbudi/roundtable
- AgentDelta is a “git diff for agent traces” tool for comparing LLM-agent runs and detecting where a prompt, reasoning path or tool choice regressed. https://github.com/sandeep-alluru/agentdelta
- Human is an AI dev-rig / software-factory project that wires tickets, docs, designs, analytics, secure sandboxing and code review into one development pipeline. https://github.com/gethuman-sh/human
- The autonomous-agentic-research-swarm repo demonstrates a repo-as-shared-memory research workflow with explicit contracts, task files, manifests, review gates and git-scoped isolation. https://github.com/AysajanE/autonomous-agentic-research-swarm
- Claude Code Subagents is a large catalog of production-oriented domain subagents that can be mined for Hermes skill/persona packaging patterns. https://github.com/0xfurai/claude-code-subagents
- MCP Servers Live Index is an auto-updated list of newly shipping MCP servers, useful as a recurring source feed for Hermes tool and integration scouting. https://github.com/linny006/mcp-servers-live
