# Hermes workflow items worth opening today

- [TODO Flow](https://github.com/JakeB-5/todo-flow) turns selected TODOs into durable parallel agent work, independent reviews, verified delivery, and a dashboard for handoffs.
- [Floxim](https://github.com/Karetski/floloom) is a terminal-first YAML workflow runner for Claude Code/Codex with resumable steps, budgets, cron-friendly execution, and JSON output.
- [Mendry](https://github.com/gmedri/mendry) packages local-first autonomous maintenance around isolated git worktrees, evidence-backed fixes, validation, and an issue dashboard.
- [ReviewLoop](https://github.com/cvsgireesh/reviewloop) watches GitHub PR feedback, lets a self-hosted coding agent prepare tested fixes, then asks for Telegram approval before pushing.
- [Agent Worksystem Builder](https://github.com/iyohesohoka646-dotcom/agent-worksystem-builder) is a Codex plugin pattern for repeatable, inspectable, resumable workflows with a coordinator, modular skills, saved state, and optional local MCP.
- [agent-hub](https://github.com/STAIxBWLB/agent-hub) sketches a local multi-harness hub where Claude Code, Codex, Kimi Code, and local workers collaborate via queued delivery and recovery records.
- [claude-crew](https://github.com/prskid1000/claude-crew) is a drop-in Claude Code crew kit with worktrees, an agent board, memory gates, evidence QA, and emulator-aware testing loops.
- [module-pipeline](https://github.com/spardanviro/module-pipeline) is a Claude Code plugin that splits a written spec into fenced module folders, runs agents in parallel worktrees, and gates each module with reviews.
- [agent-router](https://github.com/yp201/agent-router) routes Claude Code sessions across owned Claude accounts while preserving sticky cache behavior and exposing token/cache ledgers in a local console.
- [Hermes Manual Agent](https://github.com/ehsan2772e/hermes-manual-agent) shows an on-demand GitHub Actions pattern for launching Hermes from mobile, accepting a voice-note task, and returning results to Telegram.
