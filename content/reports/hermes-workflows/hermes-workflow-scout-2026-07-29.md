# Hermes workflow items worth opening today

- 🔥 Best: TokenTelemetry added a local Hermes Agent observability dashboard for tokens, sessions, tool calls, reasoning, cron, Telegram, and other gateway surfaces: [GitHub](https://github.com/VasiHemanth/tokentelemetry)
- AGNT is a local-first agent OS whose workflows, goals, memory, plugins, subagents, evals, and self-improvement loops are directly relevant to Hermes proactive-agent design: [GitHub](https://github.com/agnt-gg/agnt)
- Dagu is a single-binary local workflow engine with scheduling, retries, approvals, run history, external coding-agent CLI support, and a built-in MCP server agents can use to manage DAGs: [GitHub](https://github.com/dagucloud/dagu)
- Caliper is a lightweight evaluation harness for agent skills that runs baseline comparisons and tracks success rates across Claude Code, Codex, Pi, and Hermes: [GitHub](https://github.com/edonadei/caliper)
- Antigravity Telegram Suite shows a practical Telegram remote-control pattern for chatting with an IDE agent, switching models, managing workspaces, taking screenshots, and running multi-agent workflows from a phone: [GitHub](https://github.com/emreturkmencom/antigravity-telegram-suite)
- TrueDeck is a terminal-first multi-agent coding workbench with side-by-side Grok, Codex, Cursor, Claude, Gemini panes plus per-repo and global memory wiring: [GitHub](https://github.com/WutIsHummus/TrueDeck)
- Context Infrastructure is a reference implementation for persistent coding-agent memory, personal rules, skills, and scheduled observations that can inform Hermes memory rollups: [GitHub](https://github.com/grapeot/context-infrastructure)
- Leash is a small dashboard and watchdog for agent fleets that surfaces overnight costs, runaway loops, dead crons, failing workflows, and deliverable checks from one command: [GitHub](https://github.com/VicKayro/leash)
- OtoDock packages Claude Code and Codex as a self-hosted team of agents on a server, useful as a reference for persistent BYO-subscription agent infrastructure: [GitHub](https://github.com/OtoDock/oto-dock)
- Hope Agent combines cross-device chat, memory, autonomous goals, dynamic task orchestration, and headless NAS/cloud deployment, making it a useful comparison point for Hermes topic-scoped long-running assistants: [GitHub](https://github.com/shiwenwen/hope-agent)
