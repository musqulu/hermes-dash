# Hermes workflow items worth opening today

- 🔥 Best: cc-safety-net is a high-signal pre-execution guard for coding agents that blocks destructive git/file commands and sensitive-file access before tool calls run. [kenryu42/cc-safety-net](https://github.com/kenryu42/cc-safety-net)
- ccboard is a single-binary Rust TUI and web monitor for Claude Code sessions, costs, config, hooks, agents and MCP servers with budget alerts and forecasting. [FlorianBruniaux/ccboard](https://github.com/FlorianBruniaux/ccboard)
- ChatCrystal imports Claude Code, Cursor and Codex conversations into a local PKM with distillation, semantic search, tag graphs and MCP memory. [ZengLiangYi/ChatCrystal](https://github.com/ZengLiangYi/ChatCrystal)
- telegram-cli is an agent-first Telegram CLI with structured JSON/JSONL and skill support for Claude Code, Codex, Antigravity, Copilot, Grok, Cursor and Amp. [leynier/telegram-cli](https://github.com/leynier/telegram-cli)
- Do-SOUL-Alaya is a local-first SQLite memory plane where agents propose cross-session memories and a governance gate decides what becomes durable context. [tdwhere123/Do-SOUL-Alaya](https://github.com/tdwhere123/Do-SOUL-Alaya)
- agent-viewer is a read-only desktop window for browsing local, SSH and WSL transcripts from Claude Code, Codex, OpenCode, Gemini, DeepSeek, Hermes and Kimi. [Atituiset/agent-viewer](https://github.com/Atituiset/agent-viewer)
- hkb is a portable Hermes-style kanban layer that uses GitHub Issues as the task backend while Claude Code, Copilot CLI or Codex act as workers. [emyann/harness-kanban-board](https://github.com/emyann/harness-kanban-board)
- agent-trust-kit packages bounded handoffs for agents with explicit file packets, evidence receipts, controller-side verification and a native Hermes plugin. [mauricemohr88-debug/agent-trust-kit](https://github.com/mauricemohr88-debug/agent-trust-kit)
- watchtower is a web dashboard for inspecting coding-agent API traffic in real time across Claude Code, Codex CLI and OpenAI-compatible clients. [Shubham60019/watchtower](https://github.com/Shubham60019/watchtower)
- Concordia coordinates multiple Claude Code, Gemini CLI and Codex sessions per repo, recovers lost sessions from JSONL and produces end-of-session reports. [LUDIARS/Concordia](https://github.com/LUDIARS/Concordia)
