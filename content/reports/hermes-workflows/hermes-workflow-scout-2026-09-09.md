# Hermes workflow items worth opening today

- 🔥 Best: Clawmetry is a zero-config observability and governance layer for Claude Code, OpenAI Codex, Hermes, OpenClaw and many other agent runtimes, useful as a reference for cost/tool/error tracing. [vivekchand/clawmetry](https://github.com/vivekchand/clawmetry)
- Runvouch packages the missing unattended-agent safety layer: dead-man switch, cost cap and outcome checks for Claude Code, OpenClaw, n8n and cron jobs. [runvouch/runvouch](https://github.com/runvouch/runvouch)
- Brnrd frames a persistent reachable resident behind Claude Code and Codex that can be steered from Telegram, Slack or WhatsApp while continuing work asynchronously. [hugimuni-labs/brnrd](https://github.com/hugimuni-labs/brnrd)
- Wezbridge is a zero-dependency MCP server for orchestrating Claude Code and Codex sessions across WezTerm panes, including swarm-style spawn, prompt and read operations. [wolverin0/wezbridge](https://github.com/wolverin0/wezbridge)
- Vouch is a deterministic scanner for local agent skills that audits `SKILL.md` files for malware, prompt injection and secret-exfiltration patterns before installation. [WaelAbouceo/vouch](https://github.com/WaelAbouceo/vouch)
- SkillBench offers a controlled eval harness for measuring whether SKILL.md files actually improve agent runs versus baseline prompts or AGENTS.md instructions. [Galtonn/Vercel-SkillBench](https://github.com/Galtonn/Vercel-SkillBench)
- Aify-comms is a Dockerized inter-agent communication hub for Claude Code instances with message bus, task dispatch and dashboard concepts worth comparing to Hermes kanban. [zimdin12/aify-comms](https://github.com/zimdin12/aify-comms)
- Agent-sessions builds cross-path search and a local dashboard over Claude Code, Codex and Pi session histories, directly relevant to rollups and session recall. [aswrise/agent-sessions](https://github.com/aswrise/agent-sessions)
- Tmux Agent Pulse is a Show HN project for surfacing Claude Code and Codex status inside tmux, a compact UX pattern for terminal-native agent monitoring. [jerriclynsjohn/tmux-agent-pulse](https://github.com/jerriclynsjohn/tmux-agent-pulse)
- Blackholes is a macOS workspace for coding agents that may be useful as a product reference for local multi-agent mission-control UX. [Blackholes](https://blackholes.dev)
