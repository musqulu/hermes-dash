# Hermes workflow items worth opening today

- 🔥 Best: Repowire is a cross-project, cross-machine communication layer for Claude Code, OpenCode, Codex, Antigravity and Pi agents with Telegram in the loop. [prassanna-ravishankar/repowire](https://github.com/prassanna-ravishankar/repowire)
- Kyber runs long-lived Claude Code and Codex agents as Kubernetes pods with whole-disk persistence so workers can survive restarts, upgrades and spot preemption. [matty-v/kyber](https://github.com/matty-v/kyber)
- Codegen Orchestrator turns a Telegram project brief into a deployed app through a LangGraph pipeline of product, architect and isolated coding agents. [vladmesh/codegen_orchestrator](https://github.com/vladmesh/codegen_orchestrator)
- Jarvis Claude Code routes Claude Code sessions across Telegram, WhatsApp and Discord with per-route agents, ChromaDB/Mem0 memory, media handling and a React dashboard. [zorahrel/jarvis-claudecode](https://github.com/zorahrel/jarvis-claudecode)
- Sigil is a local-first Postgres/MCP memory layer that shares persistent context across Claude Code, Codex CLI, Cursor, Kiro and shell-capable agents. [Anmol-Srv/sigil](https://github.com/Anmol-Srv/sigil)
- Thread Keeper offers cross-session memory, skill loops and inter-agent signaling for Claude Code, Codex, Gemini, Copilot and VS Code. [po4erk91/thread-keeper](https://github.com/po4erk91/thread-keeper)
- Byori is a native multi-agent coding workspace where Claude Code and Codex share a project graph memory that outlives individual sessions. [byoridb/byori](https://github.com/byoridb/byori)
- marm-memory is a local MCP memory server for Claude Code, Codex, Grok, Gemini, VS Code and Cursor that fuses session history, codebase indexing and concept graphs. [Lyellr88/marm-memory](https://github.com/Lyellr88/marm-memory)
- tmuxbot bridges Telegram or Feishu topics to live tmux panes running Claude Code, Codex or Pi, pushing terminal output back to the same topic without headless APIs. [ztllll/tmuxbot](https://github.com/ztllll/tmuxbot)
- Passbaton provides local session continuity for Claude Code, OpenAI Codex CLI and Gemini CLI through automatic context injection, compaction handover, semantic search and error-to-solution recall. [leesgit/passbaton](https://github.com/leesgit/passbaton)
